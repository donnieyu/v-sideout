# P3-2 팀편성 공개 명령

승인 근거: 사용자의 다음 작업 진행 및 2026-10-03 결정(3~4팀만 공개, 1~2팀 초안 저장).
소유: promotion-p1의 team-draft/team-publish, sideout-teams API, 관련 테스트/검증 문서. 인증/프로필 원본과 동결 목업은 변경하지 않는다.

## 계약
- 기존 teams POST에 별도 action=publish를 추가한다. 최신 lineup과 session/roster revision, 참석 의사 확인 ID, 공개 확인 confirmed=true가 필요하다.
- 3~4개의 비어 있지 않은 팀, 모든 신청자 배정, 활성 회원·중복·자리 검증을 통과해야 한다. 6명 정원 충족이나 모든 자리 충족을 추가 요구하지 않는다.
- 초안 저장 검증을 재사용하되 공개 실패는 초안/참가자/공개본 모두 불변이다.
- 편성에 포함된 대기자만 공개 커밋에서 신청자로 전환한다. 최초공개시각은 처음 한 번만 설정한다. 기존 신청자의 누락은 재공개에서도 거절한다.
- 공개 팀/경기/참가자/초안과 revision을 한 번에 커밋한다. 이후 초안 수정은 공개본을 바꾸지 않는다.
- 공개 후 신규등록·취소 금지 및 기존 열람 범위를 유지한다.
- 권한/회원 비활성/일정·명단 충돌/재시도는 기존 원자 저장 계약으로 검사한다.

- 공개와 취소/접수의 경쟁, 재공개 시 신청자 누락, 초안 저장으로 공개본 변경.

## Ledger
- Ruling: 이번 단위는 서버 공개 기능이며 버튼/확인창을 새로 연결하지 않는다. 편집 화면은 회원 포지션 원본 인수와 승인 목업 이식에 의존한다. UI는 아직 공개 기능 이용 불가임을 보고한다.
- 기존 미커밋 작업을 보존하고 임의로 일괄 커밋하지 않는다. 테스트 로그/보고서로 변경 범위를 남긴다.
