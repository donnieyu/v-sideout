# SIDEOUT 화면 설계 — 현재 구현

2026-09-23. 기준: 승인된 C+B 적용(bdf36de) 이후 시각 QA 개선.

현행 토큰·레이아웃·접근성은 [DESIGN.md](../web/DESIGN.md), 권한·운영 규칙은 [PRODUCT.md](../web/PRODUCT.md)에 정리했다. 과거 녹색 중심 화면·하단 메뉴·모임 선택 타일·미래 인원 눈금 나열은 현재 설계가 아니다.

## 회원 홈

제목과 한 줄 설명 → All/모임 필터 → 내 소속 모임 우선 모집 카드. 각 카드의 상태·D-day, 날짜·입장/시작/종료, 장소, 인원, 참석 버튼을 유지한다. 내 소속 카드에서만 명단 확인 가능. 신청 뒤 취소와 공개 대기 팀편성 버튼, 공개 뒤 활성 팀편성 버튼. 모임 공지는 종 아이콘, 전체 알림은 사이드바.

## 운영 화면

회차·팀 구성 선택 → 신청/후보/임시/보장/배정 집계 → 포지션별 세로 코트와 신청자 도크. 빈자리 +는 검색 가능한 신청 인원/미배정/전체 회원 선택 모달이며, 전체 회원은 마스터·회장만 사용한다. 신입·임시 인원 별도 표시와 선택적 예외 배정을 유지한다. 초안과 공개본은 구분한다.

## 이번 수정

사이드바 208/248px 불일치 제거, 홈과 운영 화면의 회청색·텍스트 대비 통일, 접힌 메뉴 이름·현재 위치 표시, 모달 포커스 복귀, 44px 조작 영역, 짧은 화면 모달 스크롤과 모바일 입력 보정. 운영 설정의 정보 구조는 재설계하지 않았다.

## 확인 상태

[QA 보고서와 실제 화면](design-review/QA_2026-09-23.md)을 참고한다. 도메인 35개 통과는 기존 기록이며 이번에는 도메인 로직을 바꾸지 않았다. 타입·빌드·변경 UI detector와 실제 브라우저 흐름을 검증했다. 실제 로그인·자격 발급·운영진 지정과 실기기 테스트는 완료된 기능/검증으로 취급하지 않는다.
