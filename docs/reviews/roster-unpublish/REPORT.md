# 명단 모달 공개 취소 연결 — 2026-10-06

요청: 공개된 명단 모달에서 공개를 취소하고 인원을 수정한다. 참가 취소 시 팀편성의 배정도 함께 해제한다.

## 적용
- 운영진·마스터에게 현재 공개 중이고 팀 수정 가능한 일정에서 `공개 취소` 제공.
- 팀편성 화면과 동일한 공개 취소 확인창 재사용. 참석 회원에게 팀편성·경기 순서가 숨겨짐을 안내하고 공개 유지/공개 취소 선택.
- 저장본과 공개본이 다르면 기존 편성 선택 절차 유지. 취소 요청 직전에 최신 팀/명단 revision 조회, 서버 권한 및 revision 검증 유지.
- 완료 후 원래 명단 모달 유지, 서버에서 다시 읽어 참가자 추가 및 참가 취소 활성화.
- 실패 시 공개 상태 유지, 같은 요청 재시도. 충돌 시 최신 명단을 읽고 다시 확인하도록 처리.
- 참가 취소 확인 문구에 팀 배정 해제 명시. 기존 서버의 원자적 참가 취소+초안 배정 해제를 그대로 사용. 과거 공개 기록은 보존하며 재공개 전까지 참석 회원에게 숨김.
- 공통 공개 취소 확인창의 버튼 레이아웃을 편집 화면 전용 CSS 의존 없이 표시.
