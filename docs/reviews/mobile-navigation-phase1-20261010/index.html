먼저 비교할 부분

상세·계정의 제목은 홈과 같은 높이에서 시작합니다. 편집 화면의 점선 영역은 “같은 위치에 복귀 버튼을 추가한다면”을 보여주는 비교용 표시이며, 실제 앱에는 추가하지 않았습니다.

다음 단계에서 결정할 것

  • 팀편성: 하단 공개·공개 취소와 복귀를 한 영역에 배치할지 결정합니다. 현재 위치에 복귀 버튼을 단순히 얹으면 겹칩니다.
  • 일정 수정·등록 / 경기 순서: 상단 취소와 하단 복귀의 역할을 정하고, 입력란·경기 목록을 가리지 않는 여백을 확인합니다.
  • 오버레이: 메뉴·명단·운동 안내가 열리면 배경의 하단 복귀를 숨겼습니다. 편집기의 선수 선택·확인 창도 같은 규칙으로 검토합니다.
  • 아이폰: Safari 도구막대가 펼쳐진 상태·접힌 상태, 키보드 표시, 가로 화면은 실기기로 확인합니다.

캡처는 Chrome에서 같은 화면 크기로 확인한 결과입니다. 브라우저 자체 도구막대는 이미지에 포함되지 않습니다. 겹침 표시는 현재 캡처 위치의 사각형 비교이며 모든 스크롤 위치에 대한 판정은 아닙니다.
