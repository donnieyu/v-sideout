# 하단 복귀 1단계와 다음 비교 준비

## 적용

- 모바일 홈·상세·계정의 제목 시작 높이를 동일하게 유지한다. 상단 메뉴 유지, 상세·계정만 목적지가 표시된 하단 복귀 버튼 적용.
- 홈은 최상위이므로 복귀 버튼 없음. 데스크톱은 본문 복귀 링크 유지.
- 상세·계정에 하단 여백을 확보해 마지막 본문 조작이 복귀 위로 스크롤되도록 했다. 메뉴/운동 안내/명단 등 오버레이가 열리면 복귀를 숨긴다.
- 일정 등록·수정, 팀편성 수정/공개 상태, 경기 순서 수정은 기존 복귀/저장/취소/공개 위치를 유지했다. 아직 하단 복귀를 추가하지 않았다.

## 비교 페이지

`index.html` 또는 현재 LAN http://192.168.219.182:4192/

8개 화면 × 320×667 / 390×844 / 1280×900 × 처음/맨 아래 캡처. 화면 크기, 스크롤 위치, 적용/편집 그룹 전환과 복귀 버튼 예상 영역 표시 제공. 이미지 확대와 실제 페이지 열기 제공. 예상 영역은 가로 160px, 높이 44px, 하단 16px의 비교용 가정이며 편집기의 실제 앱에는 삽입하지 않았다.

| 화면 | 현재 조작 | 다음 검토 |
|---|---|---|
| 일정 홈 | 상단 메뉴, 카드별 신청/취소/명단/수정 | 하단 복귀 없음 유지 |
| 운동 상세 | 본문 수정·명단·운동 안내 + 하단 복귀 | 스크롤 중간 및 실제 Safari에서 가림/오탭 확인 |
| 계정 정보 | 본문 비밀번호 변경·로그아웃 + 하단 복귀 | 비밀번호 변경 전환/키보드 확인 |
| 일정 수정 | 상단 취소·저장, 본문 신청 설정 | 390px의 맨 아래에서는 예상 복귀 영역에 입력란이 겹침. 여백과 취소/복귀 역할 결정 |
| 팀편성 수정 | 상단 취소·저장, 하단 공개/다시 공개 | 390px에서 예상 영역과 다시 공개/팀 추가 등이 겹침. 하단 영역 통합 결정 필요 |
| 공개된 팀편성 | 상단 돌아가기·저장 비활성, 하단 공개 취소 | 390px에서 예상 영역과 공개 취소 겹침. 수정 가능 상태와 동일한 원칙 필요 |
| 경기 순서 수정 | 상단 취소·저장, 경기 목록 조작 | 이번 처음/맨 아래 캡처는 예상 영역 겹침 없음. 드래그/키보드/스크롤 중간 확인 필요 |
| 일정 등록 | 취소·준비로 저장·모집 시작 | 수정 화면보다 조작이 많음. 동일 복귀 규칙과 미저장 이탈 확인 필요 |

예상 영역의 겹침은 캡처 위치에서의 기하학적 비교이지 모든 스크롤 위치의 판정이 아니다. 작은 공통 하단 버튼을 일괄 삽입하지 않고 화면별 공간 정책을 정한 후 2단계에서 편집기 적용을 결정한다.

## 검증

- sideout 35개 파일/371개 테스트 통과. 명시적 opt-in 및 편집기 제외 React 검사 추가.
- TypeScript 검사·production build·수정한 TSX/테스트 ESLint·diff check 통과.
- 24개 화면/너비 조합에서 가로 넘침 확인. 모바일 홈·상세·계정 제목 y 일치.
- 실제 하단 복귀가 있는 화면은 맨 아래에서 조작 버튼과 겹침 없음.
- 메뉴/운동 안내/명단 창을 열면 배경 복귀가 숨겨지고 닫으면 복원됨.
- 직접 연 상세에서 복귀 시 주/필터 URL 보존.
- 갤러리 크기·스크롤·그룹·예상 영역 토글, 모바일 가로 넘침 검사 통과.
- 독립 읽기 전용 리뷰: 조치할 지적 없음.
- 실제 모임 데이터 쓰기 없음. 테스트 계정 로그인만 수행. 커밋/푸시/외부 배포 없음.
- Chrome 반응형 검사이며 물리 iPhone Safari 도구막대/홈 인디케이터/키보드/가로 회전은 아직 미검증.

서비스 http://192.168.219.182:4180/home 및 비교 페이지 :4192 응답 200 확인. IP는 네트워크 변경 시 달라질 수 있다.
