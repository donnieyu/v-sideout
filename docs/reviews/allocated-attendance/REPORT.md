# 배정 선수의 참석 명단 연동 검증

## 반영 기준

팀편성을 저장하면 실제 배정된 모든 선수를 `participants.status=applied`로 확정한다. 대기자는 대기 사유를 제거하고, 미신청 회원은 참석 의사 확인을 거쳐 등록한다. 기본 자리와 추가 자리에 동일한 기준을 적용한다. 공개를 기다리지 않고 함께할 인원과 명단 확인의 소속회원·게스트에 반영한다.

명단과 숫자는 기존 참가 상태 원본에서 계산하며 화면에서 별도로 인원을 가산하지 않는다. 배정되지 않은 대기자의 상태는 이 배정 처리로 변경하지 않는다. 기존 자동 대기 승격 규칙은 유지한다. 배정 해제는 참가 취소가 아니다. 저장 실패나 편집 취소는 이 참석자 전환을 반영하지 않는다. 공개 중 수정 금지와 미신청 회원 참석 확인은 유지한다.

기존 초안에 대기로 남아 있는 배정 선수는 다음 팀편성 저장 시 반영된다. 과거 저장 데이터 일괄 변경은 하지 않았다.

## 변경

- `web/lib/sideout/team-draft.ts`: 검증 및 등록 후 배정 선수의 참석 상태를 한 번에 확정.
- `web/lib/sideout/team-publish.ts`: 중복 승격 제거. 저장 로직을 공통으로 사용.
- 배정 및 저장 확인 문구를 저장 시 참석 등록 기준에 맞춤.
- 정원·마감·우선 기간 대기자, 미배정 대기자 유지, 배정 해제, 상세 조회 및 다른 사용자 조회의 회귀 검증.

## 검증 결과

- 전체 29개 파일, 288개 테스트 통과.
- TypeScript 검사 및 프로덕션 빌드 성공.
- 전용 가상 일정: 참석 3명·대기 2명에서 소속 대기자 1명과 미신청 게스트 1명을 추가 자리에 배정하여 저장. 공개 전 참석 5명·대기 1명 확인.
- 320px·390px 브라우저: 함께할 인원 5명, 소속회원·게스트 분류 및 남은 대기자 확인. 스크린샷 시각 점검 완료.
- 기존 사용자 연습 일정 2개의 팀 API 응답은 검증 전후 동일.
- 브라우저 오류 없음. 실제 iPhone 검증은 이번 작업에 포함되지 않음.
