## 사용자가 확인할 최소 시나리오

동일 Wi-Fi iPhone Safari에서 위 주소에 접속한다. 기존 시험 자격을 사용한다. 비밀번호는 문서·캡처로 공유하지 않는다.

1. 시험master: 뉴배동 · 시험 상세 진입 → 함께할 인원 옆 명단 확인 → 소속 회원·게스트·대기자 그룹 및 닫기 확인.
2. 같은 상세에서 새로고침 → Safari 뒤로가기 → 홈 복귀 확인.
3. 메뉴 → 계정 정보 → 로그아웃 → 같은 계정 재로그인 → 계정 화면 대신 홈으로 오는지 확인.
4. 시험applicant: 같은 명단에서 소속 회원과 게스트 수를 확인하고, 게스트/대기자 이름이 노출되지 않는지 확인.
5. 두 계정에서 가로 넘침·닫기 버튼 잘림·키보드에 로그인 버튼이 가려지는지 확인.

전체 8계정을 모두 수동 확인할 필요는 없다. 마스터/운영자 및 일반회원 구분은 자동 브라우저 검사로 확인했고, 사용자는 Safari 실기기 고유 문제를 보완한다. 시험 자료는 신청자 2명·대기자 1명·공개 1팀이며 경기 순서는 비어 있다. 따라서 긴 명단 내부 스크롤·3/4팀·경기 순서의 실기기 검증은 이번 자료로 완료할 수 없다.

보고 형식: `마스터 명단 / 새로고침·뒤로가기 / 재로그인 홈 / 일반회원 노출 범위 / 화면·키보드` 각각 정상 또는 문제. 문제만 화면명·누른 버튼·결과를 적고 자격 정보는 제외한다.
