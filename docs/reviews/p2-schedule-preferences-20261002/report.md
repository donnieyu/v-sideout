# P2 일정·참가·즐겨찾기 실제 저장 연결 검증

## 결과와 범위

일정 신규 등록/준비 저장/모집 시작/수정, 즐겨찾기, 본인 참가 신청·대기·취소, 운영진 명단 검색·복수 추가·취소를 실제 인증과 로컬 D1 원본에 연결했다. 사용자가 확정한 P1 명단 타일의 기존 CSS 크기는 유지했다. 팀편성/경기 순서의 편집·저장·공개, 주·부포지션 프로필 계약 연계는 후속 범위이며 이번 작업으로 완료 처리하지 않았다.

일정 저장 후에는 편집 화면을 유지한다. 성공한 값과 revision을 다음 편집 기준으로 삼고, 실패/충돌 때는 입력을 보존한다. 신규 등록 후에도 생성된 일정의 정식 주소로 이어지며 앱 복귀와 새로고침이 가능하다. 취소/메뉴/브라우저 이탈 때 저장되지 않은 변경을 확인한다.

## 우선 기간과 단일 원본

사용자 확정: **다른 모임 회원도 우선 기간 중 대기 등록 가능. 종료 후 빈자리에 등록 순서대로 승격.**

- 소속 회원은 우선 기간에 일반 정원 내 신청, 타 모임 회원은 대기한다. 정원이 차면 소속 회원도 대기한다.
- 우선/정원 대기는 등록 순서(order)로 승격한다. 취소 후 재등록하면 줄 끝으로 이동한다.
- 마감·공개 후 신규 등록은 대기이며 이 사유의 대기는 자동 승격하지 않는다. 공개된 명단은 자동 승격으로 변경하지 않는다.
- 최초 공개 후에는 본인과 운영진 모두 참가 취소 불가. 시작 후에는 신규 참가/명단 추가/취소 불가.
- 참가 취소와 초안에서 해당 선수 제거는 한 커밋이다. 공개본·최초 공개 시각은 보존한다.
- 시간이 도래한 승격은 조회/변경 요청에서 두 revision(일정/명단)을 확인하고 DB에 반영한다. 사용자별 화면 계산 결과가 아니라 같은 저장 명단을 조회한다.
- 홈·상세·열린 명단은 보이는 동안 15초마다 갱신한다. 자신의 변경은 즉시 조회한다. 조회 실패 때는 최신 정보 확인 실패 안내를 표시한다.
- 별도 예약 실행기는 없으므로 아무도 접속하지 않는 동안의 정확한 시각에 DB를 쓰거나 알림을 보내지는 않는다. 다음 조회/변경에서 정산한다. 사유/순서가 없는 기존 합성 대기자는 임의 승격하지 않는다.

## 저장·권한 경계

- 요청에서 신원을 받지 않는다. 인증 쿠키, 현재 authVersion/활성 상태/세션 유효성, 모임 관리 권한을 서버에서 확인한다.
- POST는 같은 Origin, JSON 형식, 엄격한 입력 스키마를 요구한다.
- 일정+초기 명단 생성과 명령 영수증은 D1 batch로 함께 기록한다. 같은 모임/날짜 생성 중복과 오래된 revision 수정은 거부한다.
- 같은 commandId·같은 내용의 재시도는 이미 커밋된 결과를 재생한다. 같은 ID를 다른 내용으로 재사용하면 거부한다.
- 운영진 후보 API는 해당 일정의 관리 권한을 검사하며 ID/이름/소속만 반환한다. 로그인 아이디·비밀번호·권한 원본은 반환하지 않는다.
- 회원 상태 검증과 대량 조회는 JSON 집합 쿼리를 사용한다. 새 인증 필드/마이그레이션/의존성을 추가하지 않았다.

## 독립 검토와 보완

동일 검토자 `/root/p2_schedule_preferences_review`가 일정/즐겨찾기와 정책 답변 후 추가된 참가 경로를 읽기 전용으로 검토했다. 확인된 3건을 수정했다.

1. **잘못된 시간대 오프셋 저장**: Zod datetime만으로는 `+99:99`가 허용됐다. 유한 timestamp 검사와 deadline/priority 400 검사를 추가했다.
2. **신규 저장 URL 인계**: 실제 브라우저에서 신규 저장 직후 생성용 query가 사라져 편집 진입을 잃는 문제를 확인했다. 정식 경로의 ID와 저장 상태를 복원하도록 수정했고 앱 복귀 회귀를 추가했다.
3. **D1 대량 처리 한도**: 회원별 바인딩/조회 대신 JSON 집합 조건과 일괄 최소 투영 조회로 변경했다. 100명 추가/승격 회귀가 통과했다. 원격 D1 부하 시험을 했다는 의미는 아니다.

오프셋/URL 회귀의 수정 전 실패는 `review-red.txt`에 보존했다. 코드 검토에서 그 외 확정 결함은 보고되지 않았다. 마지막 보완은 타입/자동 검사/로컬 D1/브라우저로 검증했다.
