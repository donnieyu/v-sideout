# 승인된 편집 화면·등록·운동 공지 적용

2026-10-12, promotion-p1 / feat(promotion-p1) 로컬 작업본. 사용자 승인: “이것도 승인할게. 승인되어있는 작업 진행해줘.”

## 적용 범위

| 화면 | 적용 |
|---|---|
| 팀편성 수정 | 편집 중 상단 저장·공개/다시 공개. 공개 중 상단 공개 취소만 표시. 모바일 하단 운동 상세로. 기존 배정/코트/행과 공개 확인 유지. |
| 일정 정보·경기 순서 수정 | 상단 저장, 모바일 하단 운동 상세로. 중복 취소 제거. 저장 후 편집 유지 및 미저장 이탈 확인/초안 정리 유지. |
| 일정 등록·준비 편집 | 상단 준비로 저장·모집 시작 고정. 장소·시간 요약/변경, 마감, 우선/정원 설정, 선택 공지를 하나의 내부 스크롤 본문에 표시. 최초 저장 전 홈 복귀, 저장 후 상세 복귀. 같은 일정 ID로 이어서 수정. |
| 홈 공지 | 내용이 있으면 운동 공지 모달. 장소·시간 중복 제거. 시작 전 운영자에게 공지 수정, 비어 있으면 공지 추가. |
| 상세 공지 | 본문 3줄 미리보기. 실제 넘침일 때만 펼치기/접기. 권한 있는 운영자는 기존 수정 화면의 공지 탭으로 이동. 일반 회원에게 빈 공지 영역 미표시. 공개 팀 조회의 입장 시간 유지. |

저장 중 이동을 차단하고 복귀 링크를 숨긴다. 모바일 입력 초점 및 모달에서는 배경 복귀를 숨기며, 경기 드래그 중에도 숨기고 종료 시 복원한다. PC는 기존 본문 복귀 위치를 유지한다. 서버 계약·신청/공개/명단 정책은 변경하지 않았다.

## 검증

- SIDEOUT 382개, 회원 UI 4개 통과. TypeScript 및 빌드 통과.
- 320×667 / 390×844 / 1280×900에서 일정 수정·배정·공개 편성·경기 수정·등록·상세 18개 화면 검사. 문서 가로 넘침 없음.
- 등록 본문 끝으로 이동해도 상단 작업 위치 유지. 미저장 복귀 취소/확인, 주·필터 유지, 공지 직접 진입, 공지 펼침/접기, 공개 취소 확인창에서 공개 유지 검사.
- 경기 포인터 드래그 시 복귀 숨김, Escape 후 복원. 키보드 순서 변경 후 저장하지 않고 복귀 검사.
- 코트/행 내부 스크롤: 320px 본문 291px, 390px 본문 478px 확보. 스크롤 전후 도구/하단 복귀 위치 동일. 상세는 본문 페이지 스크롤을 유지.
- 시각 검증은 기존 저장 데이터에 쓰지 않았다. 긴 공지 사례는 GET 응답만 브라우저에서 대체했다. 저장 계약은 테스트 fixture로 확인.
- 새 등록/공지/공통 변경 파일 lint 오류 0. 기존 schedule-editor 경고 2개 유지. 경기 편집의 refs lint 오류 21개는 HEAD에서도 동일하게 발생함을 비교 확인했으며 이번에 전역 lint 통과로 보고하지 않는다.
