# iPhone 잔여 확인

2026-10-06 LAN 재확인: http://192.168.0.43:4180/home HTTP 200. 같은 Wi-Fi 사용. 이후 IP가 바뀌면 재조회 필요.

검증 전용 일정: http://192.168.0.43:4180/session/8a8e9ada-a1c3-4979-84e9-8bd4f3aedc64
경기 순서: http://192.168.0.43:4180/session/8a8e9ada-a1c3-4979-84e9-8bd4f3aedc64/matches/edit
시험 마스터로 확인. 21명 공개 상태이며 별도 가상 일정이다. 기존 연습 일정은 수정할 필요 없다.

1. 경기 순서: 손잡이를 끌어 위/아래 이동, 화면 끝 자동 스크롤, 저장 후 편집 유지와 상세 반영 확인.
2. 팀편성: 공개 취소 확인창의 취소/확인, 편집 가능 전환, 미신청 회원 필터 열기·닫기와 검색 중 선수 목록 높이 확인.
3. 저장하지 않은 변경이 있을 때 브라우저 뒤로 가기, 취소 버튼 확인. 하단 버튼이 Safari 도구막대·safe area에 가리지 않는지 확인.

이전에 사용자 확인 완료: 검색 키보드 상태 후보 선택, 배정↔미리보기 이동, 저장 후 편집 유지. 이를 미확인으로 되돌리지 않는다. 최신 필터/공개 취소·경기 DnD 확인은 별도다.
여러 계정 재로그인은 필수 아님. 권한별 서버 결과는 6계정으로 자동 검증했다.
