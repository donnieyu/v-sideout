## 구현

- MemberLabel/후보 응답에 homeClubId를 포함하고 모임 ID로 소속/게스트를 구분한다. 같은 이름의 다른 모임, 이름 변경, 무소속을 구별한다.
- 독립 검토에서 공개 참석 회원 비활성화 후 재공개 교착 발견. 사용자 확정에 따라 공개 명단은 유지하고 기존 공개 배정을 동일한 팀/자리/포지션에 유지할 수 있게 했다.
- 비활성 회원은 후보에서 제외되며 새 자리 이동·저장 해제 후 재삽입은 거절한다. 해당 배정 해제 저장 시 현재 참석에서도 제외하여 재공개 가능. 공개 취소 중 보관된 이전 공개본은 변경하지 않는다. 활성 회원 배정 해제는 참석 상태를 바꾸지 않는다.
- 비활성 유지/해제의 저장도 회원 활성 상태·버전을 원자적으로 확인한다. 동시에 재활성화되면 409로 거절한다. 인증 소유 코드/스키마는 변경하지 않았다.
