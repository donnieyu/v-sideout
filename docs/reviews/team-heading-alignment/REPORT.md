# 팀명·수정 아이콘·인원 수 정렬

- 왼쪽: 팀 이름 바로 옆 수정 아이콘. 오른쪽 끝: 고정 폭 인원 수. 빈 팀 삭제 버튼은 인원 수 왼쪽에 표시.
- 이름은 1~40자 저장 규칙 유지. 긴 이름은 왼쪽 영역 안에서 줄바꿈하여 전부 노출하고 제목 영역 높이만 확장한다.
- 수정 아이콘 및 인원 수는 첫 줄 기준 위치 유지. 말줄임/자동 흐르기 없음. 아이콘 터치 44×44px 유지.
- 기존 UI 회귀 19개 테스트 통과, production build 성공.
- 320/390/1024px 브라우저에서 짧은 이름→40자 이름 변경 전후 인원 수 x좌표와 제목 상단 기준 y좌표 동일. 가로 넘침 없음. 스크린샷 직접 확인.
- 검증은 별도 가상 일정의 미저장 편집만 수행, 서버 데이터 변경 없음. 실제 iPhone 조작 미검증.
