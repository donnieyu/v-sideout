# 독립 최종 리뷰 및 조치

- 리뷰어: `/root/phase1_final_review`, 읽기 전용 독립 검토.
- 검토 범위: `06418b7778374b5c9ff40b8f3bf21e8a67ea78b2..6025df4549b02ab18e77430560bf196a36a237e0`의 커밋된 제품 코드·관련 테스트·현행 승인 문서.
- 판정: **병합 가능 — Critical 0 / Important 0 / Minor 1.**

## 확인 내용

신규 진입 시 무저장, 저장 후 편집 유지와 모집 상태 보존, 상세의 모집 확인, 중복 작업 방지, 계정 재검증 시 확인 취소, 명단 부모 창 유지, 편집 이탈 보호, 모바일 작업 그룹, 자동 배치 사유 무효화 및 서버 권한·revision·명령 재시도 경계를 확인했다. 리뷰어는 기존 격리 검증 기록을 검토했으며 전체 검사를 직접 재실행한 것은 아니다.

## Minor 1 — 해결

팀편성 스크롤 검사에서 이전 Shell 링크 `[data-return-placement]`를 찾으나 현재 편집 화면은 `[data-floating-editor-actions]`를 사용한다. 제품 문제는 아니지만 검증 스크립트가 null 오류로 중단된다.

담당자가 실제 로컬 시험 서버에서 기존 스크립트의 `getBoundingClientRect` null 오류를 재현했다. 선택자를 현재 작업 그룹으로 변경하고 존재 여부 오류를 명시했다. 수정 후 Chrome 320×667, 390×844의 코트·행 4조건 모두 통과했다. 도구/하단 그룹 위치 유지, 내부 스크롤, 가로 넘침 0을 확인했다. 로그인·조회·보기 전환만 실행했으며 선수/일정 데이터를 저장하지 않았다. `scroll-verification.jsonl` 참조.

## 판정 한계

- 실기기는 사용자의 인수이며 리뷰어의 직접 확인으로 표시하지 않는다.
- 전체 스크린리더·200% 확대, 별도 인증/PBKDF2/호스팅 변경 및 운영 DB·배포는 제외한다.
- 팀 순서 DnD·코트 팀명 진입 등 후속 설계를 이번 단계 완료로 처리하지 않는다.
- 제품 web 범위 whitespace 검사는 통과했으나 보존된 원본 빌드/검사 로그에는 후행 공백이 있다. 전체 diff가 whitespace-clean이라고 주장하지 않는다.
