# 승인 UI → SIDEOUT 이전 대응표

작성: 2026-09-30 · 현행 기준 재대조: 2026-10-07. **승인된 P1~P4 앱 변경 main 및 origin/main 반영 완료; 신규 실기기 인수·회원 기능 합류·운영 배포는 잔여**.

최신 범위·검증·잔여 순서: [메인 통합 기록](main-integration-20261007/REPORT.md).

이번 현재 상태 표는 최신 사용자 결정과 실제 구현을 우선한다. 아래 날짜별 이력은 당시 기록이며 현행 규칙을 덮어쓰지 않는다. 재대조 전 표는 [보존본](p4-integration-20261006/parity-before.md), 이번 순차 작업과 검증은 [실행 기록](p4-integration-20261006/progress.md) 참조.

## 판단 기준

사용자가 확정한 a-shadcn의 화면·상호작용을 복원한다. 구현이 다른데 비슷한 이름의 버튼이 있다는 이유로 완료 처리하지 않는다. 최신 사용자 결정 → 승격 설계 → 보존된 목업 순으로 판단한다. 과거 A/B나 독립 position-slots 화면은 기능 원본으로 되살리지 않는다.

원본은 [2026-09-30 보존본](../design-review/baselines/2026-09-30-approved-ui/README.md)의 `prototype-source.tar.gz`이다. 아래 `src/...:줄`은 **그 아카이브 내부 경로**이며 현재 운영 코드 경로가 아니다. 검토 대상은 App에서 연결된 7개 경로, 모든 대화상자, 상태 모델, CSS 반응형 분기, 상호작용 테스트다. 원본의 샘플 데이터·클라이언트 권한·고정 시각은 운영 구현으로 복사하지 않는다.

상태 표기:
- **연결**: 실제 인증·서버 조회가 연결되어 있음. 별도로 명시하지 않은 시각·실기기 검증까지 의미하지 않음.
- **보완**: 이번 변경에서 원본 구조를 복원했으며 검증 기록을 아래에 남김.
- **차이**: 조회 화면에도 현재 남아 있는 차이. P1 완료 표현으로 덮지 않음.
- **미연결**: 목업에는 동작하지만 실제 서비스 쓰기·자식 화면이 아직 연결되지 않음.
- **별도**: 제품 범위 결정 또는 다른 인증 작업과 합류가 필요함.

- 모임 공간 게시판: 기존 web 보존, 새 셸 편입·메뉴 노출 정책 별도.
