# 상단 안내 제거와 빈 후보 탭

적용: 상단 포지션 안내 제거. 인원 0과 무관하게 신청자/대기자/미신청 탭 선택 허용. 신청자 자체가 없는 경우와 전원 배정한 경우를 구분. 대기자 없음/전원 배정 안내도 목록 내부에 표시.
검증: 관련 26 테스트 통과, 타입 및 빌드 성공. 320/390px에서 빈 탭 왕복, 안내 제거, 빈 목록 안내 및 가로 넘침 없음 확인. 사용자 데이터 쓰기 없음.

## 필터 디자인 검토 (미구현 권장안)
현재 필터 버튼 줄은 모바일 44px. 별도 줄의 초기화와 드롭다운 하단 전체 버튼, 설명 문장이 시각적 밀도 및 패널 높이를 증가시킨다. 드롭다운 자체는 오버레이이므로 평소 목록 높이를 감소시키는 직접 원인은 상시 필터 버튼 줄이다.
권장: 검색창 오른쪽 44px 필터 아이콘 하나 + 적용 조건 개수 표시. 별도 필터 버튼 줄 제거로 약 44px 확보. 모임/포지션 통합 패널의 두 섹션, 선택 항목은 옅은 배경과 작은 체크로 표시하고 행 전체 터치 가능하게 한다. 초기화는 패널 제목 행으로 통합, 소속 모임 전체/바깥 초기화 제거. 선택 즉시 반영, 바깥 탭으로 닫기. 패널은 제한된 최대 높이와 내부 스크롤을 사용한다.
대안: 기존 버튼을 작게 줄이는 방법은 즉시 필터에 접근할 수 있으나 상시 한 줄이 남고 터치가 어려워져 권장하지 않는다.
