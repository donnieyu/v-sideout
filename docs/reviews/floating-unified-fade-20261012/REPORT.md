# 하단 플로팅 페이드 통일

사용자 요청에 따라 단독 복귀와 편집 작업 그룹에 같은 CSS 변수의 그라데이션을 적용했다. 기존 0/28/62%에서 0/42/82% 불투명도로 높였다. 단독 복귀 버튼의 가상 요소는 화면 너비로 중앙 정렬되며 터치를 가로채지 않는다. 모달에서는 버튼과 함께 숨겨진다. PC에는 적용하지 않는다.

빌드 통과 및 4180 서버 재시작. Chrome 320/390/1280px 상세·일정 편집·공개 팀 편집 9개 화면 검증: 같은 그라데이션, 버튼 높이 44px, 가로 넘침 없음, PC 배경 없음, 공개 취소 모달에서 버튼 그룹 숨김. 화면 PNG, verify.mjs/browser.json 참조. 실제 일정 데이터 변경 없음. 실기기 검증은 별도.
