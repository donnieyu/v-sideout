# 공개 취소 후 팀편성 수정

승인된 설계: 공개 중 읽기 전용 → 확인 후 공개 취소 → 편집/저장 → 3~4팀 전체 신청자 배정 검증 후 재공개. 참가 신청/취소 잠금은 최초 공개 이력에 따라 유지. 경기 순서 단독 저장 정책은 유지. 사용자 일정 데이터는 검증에서 변경하지 않음.

- [x] 현재 공개와 최초 공개 이력 분리. publicationState 기본 생략은 기존 published 데이터로 판단. withdrawn도 공개 스냅샷 보존.
- [x] 서버 save/publish 잠금 + confirmed unpublish command, revision/권한/운동 시작/중복 명령 검증.
- [x] 공개 취소 시 source=saved|published 선택. published 선택으로 덮일 기존 초안은 withdrawnDraft에 보존.
- [x] detail/home/경기순서 조회는 실제 공개 상태에 맞춰 노출; 운영진도 공개 중에는 실제 공개본 조회.
- [x] 편집기 읽기 전용: 저장/배정/해제/팀변경 잠금, 조회 내비게이션 유지. 공개 취소 확인 및 성공 이후 편집 허용.
- [x] 오래 열린 화면에서 리비전 변경 시 잠금 재확인; 서버가 최종 결정. 테스트→types→build→320/390px 화면 및 격리 시험 일정 E2E.
