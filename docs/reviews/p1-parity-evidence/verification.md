# P1 사용자 피드백 보완 및 전체 이전 대조

2026-09-30. 대상 `feat/promotion-p1`, 변경 전 `99b1bad50ab30c9b0631df2e529ab0a339fba6da`.

## 원인과 수정

1. 계정 페이지의 인증 gate가 로그아웃 후에도 `/account` 경로를 유지해 재로그인시 계정 페이지가 다시 렌더됐다. 명시적 로그아웃 성공 시에만 `/home`으로 replace한다. 실패하면 이동하지 않고, 상세 직접 URL의 로그인 복귀는 유지한다.
2. 홈의 명단 오버레이가 빠지고 상세는 인라인 disclosure로 축약됐다. 공통 `RosterButton`을 양쪽에 연결해 원본의 소속/게스트/대기자 타일·내부 스크롤·닫기·포커스 복귀를 복원했다. 운영진 대기자 명단은 서버 권한 검사 후에만 반환한다. 추가/취소는 P2 쓰기 연결 전까지 disabled다.
3. 원본 상세의 이름/소속/포지션 팀 명단 표 대신 편집 미리보기의 코트 UI를 가져왔다. 상세는 표로 복원하고 정보/함께할 인원 카드를 원본에 맞게 배치했다. 코트 미리보기는 P3 편집화면의 인수 대상으로 유지한다.

## 독립 검토 및 처리

`requesting-code-review` 방식의 별도 에이전트 `promotion_parity_review`가 미커밋 코드와 승인 원본/대응표를 읽기 전용으로 검토했다. 인증 전체를 다시 검토하거나 운영 서버 쓰기를 시험한 검토는 아니다.

- Important: 로그아웃 대기 중 focus/visibility 재검사가 generation을 바꿔 홈 이동 콜백이 생략되는 경합. 지연 logout + 포커스 복귀 테스트로 실패를 확인한 뒤 로그아웃 중 재검사를 차단하고 중복 로그아웃도 막았다.
- Important: 운영진 상세의 저장된 초안 우선 조회/‘저장된 초안’ 표기가 대응표에서 빠짐. DETAIL-04를 현재 조회 차이로 고치고, DETAIL-06에 공개 전 예시 카드/과거 제목도 기록했다.
- 검토자가 확인한 개인정보 노출 결함은 없음. 이 표현은 전체 제품 무결함 보장이 아니다. 재검토 에이전트는 추가 실행하지 않고 구현자가 실패/성공 시험과 수정 diff를 확인했다.
