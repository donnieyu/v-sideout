# 팀편성 화면 전환 시 맨 위로 이동

2026-10-06 · 사용자 요청에 따른 스크롤 정책 변경

비교: 선택 팀 위치를 복원하면 배정 직후 같은 팀을 확인하기 쉽지만 상단 코트/행/자동배치 도구가 가려지고 화면의 시작 위치가 달라진다. 맨 위에서 시작하면 전체 편성과 도구를 예측 가능한 위치에서 확인할 수 있지만 하단 팀을 다시 보려면 스크롤해야 한다. 현재 미리보기를 전체 팀 검토와 구성 조작에 사용하는 목적에 맞춰 맨 위를 채택했다. 이전의 선택팀 자동 이동 승인보다 이번 명시적인 변경 요청이 우선한다.

변경: 선택한 타일의 scrollIntoView 제거. overview/view 전환 후 layout effect에서 창과 편집 내부 스크롤 영역의 scrollTop을 0으로 초기화한다. 팀·포지션 선택 및 배정 데이터는 유지한다. 선수 배정 자체나 목표 자리 변경만으로 스크롤을 다시 초기화하지 않는다.

검증:
- 새 회귀 테스트는 기존 코드에서 scrollTop 240 유지로 실패했고 수정 후 통과했다.
- SIDEOUT 전체 259개, 타입 검사 및 빌드 통과.
- 320/390/1024px 실제 브라우저에서 C팀 세터 선택 → 미리보기 → 행/코트 → 배정하기 검사.
- 모든 전환에서 세로 스크롤 0, C팀 세터 선택 유지 확인.
- 서버의 저장 배정 데이터 전후 동일, pageerror 없음.
- 실제 iPhone은 이번 변경에 대해 별도 미검증.
