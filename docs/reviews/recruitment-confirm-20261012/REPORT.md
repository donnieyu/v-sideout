# 모집 시작 확인 — 2026-10-12

공통 PreparedScheduleView의 모집 시작 동작 앞에 기존 앱의 브라우저 확인 방식을 적용했다. 회원 공개 및 참석 신청 가능 안내 후 확인했을 때만 onStart를 실행한다. 신규/기존 준비 일정 모두 동일하며 취소 시 쓰기 요청 없음.
