# 일정 상세 및 편집 버튼 통일

- 상세의 일정/팀편성/경기 순서 수정은 공통 EditButton 사용: 연필+수정, 68×44px, outline, 제목 오른쪽. 화면별 접근성 이름과 권한/링크 유지.
- 편집 화면 공통 EditorActions 사용: 취소(왼쪽 outline), 저장(오른쪽 primary+Save), 68×44px. 팀편성의 누락된 취소를 기존 onCancel/변경 확인 흐름에 연결.
- 초안 저장 버튼의 표시는 저장으로 통일. 신규 일정 등록의 준비로 저장/모집 시작, 팀편성 하단 공개는 의미가 다른 작업으로 기존 정책 유지.
- 저장 중 중복 저장 및 취소 비활성. 저장 후 편집 유지 및 실패 재시도 기존 계약 유지.

## 검증

- SIDEOUT 28개 테스트 파일, 260개 테스트 통과. 새 취소 콜백 검증 및 저장 중 취소 비활성 검증 포함.
- TypeScript 검사 및 production build 통과.
- browser.json: 320/390/1024px에서 상세 수정 3개 스타일 동일, 편집 3곳 저장 스타일 동일. 취소→저장 한 행, 44px 높이, 가로 넘침 없음.
- 일정/팀편성/경기 순서에서 변경 후 취소 확인창 거절은 편집 유지, 확인은 상세 이동 검증.
- 브라우저 검증은 시험 일정에서 저장 요청 없이 수행. 실제 사용자의 신청/편성 데이터 변경 없음.
- 모바일 크기 브라우저 검증이며 실제 iPhone 확인을 대신하지 않음.
- 공통 컨트롤 디자인 검사 결과 없음.
