# 명단 보완 적용 및 컴팩트 타일 제안 — 2026-10-02

## 승인 범위 적용

인원수 배지/그룹 제목, 한국어 날짜, 제목·설명 타이포그래피를 복원하고 명단 region에 키보드 포커스 및 가시적 표시를 추가했다. 4180 로컬 앱을 빌드 전 중지하고 재빌드 후 동일 D1 상태로 다시 실행했다. Node24.16.0 사용. 제품의 타일 높이·간격은 변경하지 않았다.

## 추가 제안 (제품 미적용)

- 소속 회원: 이름14px 유지, 타일 최소높이50→40px.
- 게스트·대기자: 이름14px/소속11px 유지, 최소높이48px. 긴 이름·소속은 줄바꿈하며 필요한 만큼만 늘어난다.
- 간격7→6px, 좌우padding10→8px, 세로4px.
- 취소 버튼이 있는 행: 최소52px, 버튼 터치영역44×44px 보장. 모두40px로 줄이지 않는다.
- 390px2열/320px1열/PC3열 유지. 모바일3열은 이름·소속·취소 영역을 좁히므로 권하지 않는다.

같은 가상28명에서 공개상태 390px의 완전히 보이는 소속 회원 수는14→18명이다. 글자를 줄이거나 말줄임으로 숨기지 않고 공간을 확보했다. 고정650px dialog 높이 자체와 적은 인원에서 남는 빈 공간은 이번 타일 제안과 별개로 유지한다.

[비교 화면](comparison.png) / [실측](metrics.json). compact-preview-only.css는 시험 브라우저에만 주입했으며 실제 앱CSS에 포함하지 않았다. 실제 DB 명단도 변경하지 않아 iPhone 시험 명단은 여전히 소수다.
