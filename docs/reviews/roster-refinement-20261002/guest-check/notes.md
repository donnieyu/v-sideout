# 소속명이 있는 타일 추가 시각 확인

이전 검증은 소속이 있는 가상 게스트/대기자의 높이와 overflow도 포함했지만, 사용자에게 제공한 상단 캡처에는 게스트가 보이지 않았다. 이번에 390px의 목록 하단을 직접 촬영하고 두 이미지를 열어 확인했다.

- 공개 상태: 이름14px/소속11px 두 줄, 최소48px. 짧은 소속과 긴 소속을 모두 확인.
- 공개 전: 취소44×44px 공간을 확보하며 최소52px. 긴 소속은 줄바꿈되어 필요한 만큼 타일이 늘어난다. 48px 고정높이로 제한하지 않는다.
- 가로 overflow·PageDown·목록끝 스크롤 검사 통과. 실제Safari시험/서버DB변경 없음. 타일compact CSS는 여전히 브라우저시험주입만 사용하고 제품CSS에는 적용하지 않았다.
