## 원인과 수정
편집기는 roster.draft에 저장했지만 상세 조회와 화면은 publishedTeams/publishedMatches만 읽었다. 공개 전에는 실제 저장본 대신 예시가 보이고, 공개 후 초안을 바꾸면 운영진도 이전 공개본을 보았다.

운동 시작 전 권한 있는 운영진 상세에 managerTeamPreview를 추가하고 실제 draft와 draftMatches를 함께 표시한다. 공개본과 다르면 `저장본 · 미공개 변경`, 같으면 `저장본 · 공개 완료`를 명시한다. 일반 회원에게 이 필드는 반환하지 않고 기존 공개본·열람 정책을 유지한다. 운동 시작 후에는 공개본을 표시한다. 저장/공개 자체의 데이터와 권한 규칙은 변경하지 않았다.

회귀 테스트는 공개 전/후 관리자·운영자·신청자·대기자·게스트, 운동 시작 이후, UI에서 이전 공개팀 대신 저장팀/경기표 표시를 포함한다. 수정 전 3개 실패를 확인했다. 이후 SIDEOUT 201개 전체 테스트, 타입 검사, build 통과.
