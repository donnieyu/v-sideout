# 공개 후 추가 접수 차단 — 2026-10-02

사용자 요청으로 이전 공개 후 대기 등록 정책을 대체했다.

## 적용 규칙
- 공개(최초 공개 기록 또는 현재 공개본 존재): 본인/운영자/마스터 신규 등록 불가. 신청 마감 전이어도 적용.
- 공개 전 일반 마감 후: 대기 등록. 우선 기간 외부 회원: 대기 등록. 정원 초과: 대기 등록.
- 우선 기간 종료 후: 우선/정원 대기를 등록 순서대로 정원 여유만큼 승격. 공개/운동 시작 후 승격하지 않음. 일반 마감 후 신규 대기는 자동 승격 대상 아님.
- 기존 공개 일정의 대기 명단은 보존. 공개 후 취소 제한도 유지.

## 구현 범위
- `web/lib/sideout/participation.ts`: 공통 등록 허용 정책, 공개 후 등록 거절.
- `web/lib/server/sideout-query.ts`: 홈/상세 신청 가능 여부와 명단 변경 권한 정합성.
- `web/lib/server/sideout-participation.ts`: 공개 일정 후보 조회 거절. 원자 revision 검사로 공개와 등록의 동시 요청 방어.
- `web/components/sideout/{roster-dialog,participation-button,home}.tsx`: 공개 후 추가 숨김/접수 종료, 열린 추가 창에 공개 상태 반영.
- 자동 승격은 기존 조회/변경 시점의 원자 저장 방식을 유지. 열린 홈/상세/명단은 15초 주기 조회. 별도 예약 작업은 없음.
