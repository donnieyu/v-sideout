# P3-1 팀편성 초안 저장 기반 — 2026-10-02

## 완료 범위
- 운영진 전용 `/api/sessions/:id/teams` GET/POST. 서버 검증 신원, 실제 회차 권한, session/roster revision, idempotency receipt와 D1 batch 저장을 재사용.
- 1~4팀 초안, 비어 있는 팀 허용. 중복 팀/선수/자리, 잘못된 코트 포지션, 미정의 자리, 비활성·취소 회원 배정 거절. op2/bench 추가 자리 지원.
- 미신청 확인 ID와 실제 등록 대상 정확 일치 검사. 신규 등록은 공통 우선/정원/마감 규칙에 따라 신청자 또는 대기자. 공개 후 신규 등록 우회 금지.
- 초안 저장은 공개 팀·공개 경기·최초 공개시각을 보존. 대기자를 배정해 저장해도 공개 참석자로 승격시키지 않음(기간 만료에 따른 공통 자동 승격은 저장 전에 원자적으로 정산).
- 실제 팀 ID로 3팀3라운드·신입사이, 4팀1라운드·신입앞뒤 기본 대진 생성. 팀 ID 집합 동일 시 수정된 경기 순서 보존. ID 집합이 달라지면 초안 경기만 재생성.

## 근거와 검증
- 승인 목업 소스는 일반 작업 디렉터리보다 `docs/design-review/baselines/2026-09-30-approved-ui/prototype-source.tar.gz`가 최신임을 확인. 보존본 수정 없음.
- 도메인 및 SQLite D1 신규 검사 22개. 전체 sideout 159개, member UI 4개 통과; TypeScript, build, diff-check 통과.
- 독립 검토: `/root/p3_storage_review`, 파일 편집 없이 별도 검토. 차단 결함 없음. 일정 경합/FIFO/시작 경계 테스트 보완 의견을 반영.
- 실제 LAN HTTP + 로컬 D1: 합성 계정으로 새 회차 생성, 참가 2명, 부분 초안 저장, 같은 명령 재시도 200/버전1회증가, 오래된 명령409, 실제 A/C/D 대진11경기, 일반회원 초안GET403. 브라우저 오류0. `browser.json`, `verify-storage.mjs` 참조.
- 서버를 새 빌드로 재시작. 실물 iPhone 검증, 원격 배포, 커밋/병합은 수행하지 않음.

## 남은 범위와 정책
- 공개 명령은 아직 없음. 1~2팀 공개 허용 여부 사용자 답변 대기.
- 편집 UI·자동배치·경기 순서 편집 미연결. 현재 상세의 비활성 편집 버튼을 완성된 것처럼 활성화하지 않았음.
- 회원 포지션 원본은 auth-rotation의 `member_position_profiles`이며 현재 promotion-p1에 미인수. 스키마나 포지션을 병행 생성하지 않았음. 프로필 인수 후 승인된 최신 UI 어댑터에 연결할 예정.
- 1~2팀 초안의 기본 경기순서는 null. 신규 공개 정책이 확정되면 해당 규칙을 구현.
