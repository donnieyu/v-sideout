# M3 기존 회원 접근 화면 인계

작성: 2026-09-30 · 담당 A(회원·인증)  
기준: [회원 SSOT](../ACCESS_AND_DEPLOYMENT_SSOT.md), [M3 계획](../superpowers/plans/2026-09-30-member-access-ui.md), [M2 인계](MEMBER_MANAGEMENT_M2_HANDOFF_2026-09-30.md).  
소스: `feat/auth-rotation`의 `2e618f0`. 이 인계는 화면 컴포넌트 완료를 뜻하며 운영 라우트 연결은 포함하지 않는다.

## 제공한 화면·클라이언트

- `web/lib/member-access-client.ts`는 세션 확인, 로그인, 비밀번호 변경, 로그아웃과 마스터 회원 API를 같은 출처 쿠키·`no-store`로 호출한다. 서버 오류 코드/메시지, 네트워크 실패, 비정상 응답을 `MemberAccessError`로 반환한다. 비밀번호와 세션 토큰을 로컬 저장하거나 URL에 넣지 않는다.
- `MemberAccessGate`는 서버의 `SessionView`를 읽어 익명 로그인, 첫 변경 필수, 활성 계정 상태를 렌더링한다. 새로고침 시 서버 상태를 다시 확인한다. `renderActive(session,actions)`를 I가 제공하면 실제 앱을 렌더링할 수 있고 `actions.changePassword()`와 `actions.logout()`을 계정 메뉴에 연결할 수 있다. 기본 활성 화면도 일반 비밀번호 변경을 제공한다.
- `LoginForm`은 한글/영문 닉네임 아이디와 비밀번호를 받고 내부 공백을 안내한다. `onJoinRequest`는 **M4 실제 신청 화면이 연결될 때만** 표시한다. 분실 도움은 기존 연락 경로의 마스터에게 재발급 요청을 안내한다.
- `PasswordChangeForm`은 첫 변경과 일반 변경을 같은 규칙으로 처리한다. 현재 비밀번호·새 비밀번호·확인만 입력받고, 8자 이상 영문·숫자 포함과 동일값/불일치를 클라이언트에서 안내한다. 서버가 최종 검증 기준이다. 첫 변경 화면에는 건너뛰기 동작이 없다.
- `MemberAdmin`은 실제 `api/members`에 목록/검색/상태 필터, 수동 등록, 프로필/권한 수정, 재발급, 비활성/재활성을 연결한다. `clubs?: ClubOption[]`은 I가 운영 모임 원본에서 전달한다. 미연결이면 무소속 등록만 노출하고 소속 계정 수정을 막는다. 목록·상세에 소속/추가 모임 역할과 첫 변경 대기 계정의 임시 자격 만료를 표시한다. `TemporaryCredential`은 성공 응답의 새 자격만 한 번 표시하고 닫으면 컴포넌트 상태에서 폐기한다.
- 회원 선택·재등록·목록 다시 불러오기 전 미저장 입력이 있으면 이동/폐기 선택지를 보여 주고, 새로고침·탭 종료에는 브라우저 경고를 건다. `onDirtyChange?(dirty:boolean)`을 부모에 전달하므로 I는 내부 라우트 이동과 브라우저 뒤로가기를 막는 앱 셸 경계에 연결해야 한다. 이 연결 전에는 화면 간 이동 보존이 완성되지 않았다.

## I의 연결 작업

I가 소유한 공개/보호 라우트와 앱 셸에 컴포넌트를 배치한다. `GET /api/auth/session`의 활성 상태만 업무 앱으로 넘기고, 제한 상태에서는 첫 변경 화면만 열어야 한다. 활성 화면의 계정 메뉴에서 일반 비밀번호 변경과 로그아웃을 연결한다. 마스터 화면은 서버의 마스터 검사에 더해 메뉴 노출도 통합해야 한다. `SessionView`는 마스터 여부를 브라우저에 담지 않으므로 `api/members` 접근 결과를 현재 권한의 근거로 삼거나 I의 별도 서버 렌더링 계약을 사용해야 한다. `MemberAdmin.onDirtyChange`를 실제 내비게이션 차단/확인 흐름에 연결하고 직접 URL·뒤로가기에서 입력 보존을 확인해야 한다.

운영 모임 ID 제공자와 화면 선택지의 같은 서버 원본은 I 담당이며 아직 연결되지 않았다. 컴포넌트의 `clubs`는 합성 브라우저 미리보기에서만 예시 목록을 받았다. 실제 라우트에서 `EXAMPLE_CLUBS`를 운영 정본으로 주입하지 않는다. 가입 신청 링크는 M4 기능 완료 뒤 연결한다. 최초 마스터 설정 명령, 실회원 등록/임시 자격 전달, 업무 API·원격 D1·공개 URL도 미완료다.

## 검증

- Node 24.16.0에서 전체 17개 `web/tests/*.mjs`, 타입 검사, 빌드, 변경 파일 ESLint를 통과했다. 새 클라이언트 검사는 요청 경로·메서드·쿠키/캐시 옵션, 인증 전환, 관리 명령, 충돌·네트워크·비정상 응답을 포함한다.
- 합성 데이터만 쓰는 임시 로컬 미리보기에서 로그인→첫 변경 화면, 아이디 내부 공백 오류, 회원 등록→일회성 임시 비밀번호 표시·닫기, 데스크톱과 390/320px 레이아웃을 확인했다. 추가로 무소속 계정의 단일 추가 모임 역할 표시/편집, 임시 자격 만료, 편집 후 회원 전환 차단·계속 수정 시 입력 보존·명시적 폐기 이동을 확인했다. 문서상 임시 자격은 합성값이며 실제 자격이 아니다. 미리보기 경로·서버는 검증 뒤 제거했다.
- `impeccable detect`는 오류 표시 CSS의 옆선 장식 2건을 지적했다. 사방 테두리로 바꾸고 모바일 오류 화면을 다시 확인했다. 독립 코드 검토에서 잘못된 회원 응답 처리, 세션 기한 오표시, 역할/추가 권한 표기, 미저장 전환·만료 정보 누락을 지적하여 수정했다. 재검토는 데이터·표시·같은 화면의 미저장 보호를 확인했고, 내부 라우트 이동과 키보드 초점 보완을 요청했다. 부모 dirty 계약과 경고 버튼 초점 이동을 추가한 뒤 타입·lint·전체 검사·빌드가 통과했다. 실제 계정/DB의 브라우저 로그인, 화면 읽기 프로그램, 운영 모임 선택지, 앱 셸 통합은 아직 검증하지 않았다.
