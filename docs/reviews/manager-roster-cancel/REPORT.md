# 명단 모달 운영진 취소 복구 — 2026-10-06

원인: 직전 변경은 운영진 추가를 현재 공개 여부 기준으로 열었지만, 취소는 최초 공개 이력으로 계속 잠갔다. canCancelRoster=false가 내려와 버튼이 숨겨지고 직접 API도 거절했다.

이번 사용자 보고에 따라 운영진 취소를 추가와 같은 조건(모집 중·현재 미공개·운동 시작 전)으로 통일했다. 공개 취소 후에도 기존 신청자/대기자의 등록을 취소할 수 있다. 일반 회원 본인 취소의 마감·최초 공개 이력 제한은 유지한다. 운영진 오류 메시지도 현재 공개 상태를 기준으로 한다.

취소 확인 후 참석 상태와 초안 배정을 함께 제거하며, 보관 중인 이전 공개 팀/경기 순서는 변경하지 않는다. 재등록된 활성 회원은 참석자가 되지만 이전 배정은 자동 복원하지 않는다. 모달 열림 상태는 유지한다.

검증: 새/변경 회귀 5개 실패→수정. 전체 SIDEOUT 305개, 회원 UI 4개, TypeScript, production build 통과. 공개 중 및 운동 시작 -1/0/+1ms 경계, 일반 회원 권한, 공개 경합, 명단·초안 원자 정리, 재등록 회귀 포함.

실제 브라우저 390px에서 별도 검증 일정의 공개 취소 상태로 소속회원·게스트 2명을 연속 취소했다. 확인창 취소는 명단 유지, 확인은 모달 유지 및 참석 수/명단/초안 배정 일치, 이전 공개본 보존. browser.json과 before/after-390.png 참조. 기존 사용자 일정 2건의 저장 데이터는 변경하지 않았다.
