# 경기 순서 드래그 개선 / 상세 코트 추가 인원 축소

2026-10-06 · 실제 앱 promotion-p1 · 로컬 4180 반영

## 구현

- 기존 Pointer Events를 유지하고 드래그 처리를 `use-match-drag.ts`로 분리했다. 추가 패키지는 설치하지 않았다.
- 손잡이에서 6px 이상 이동해야 드래그를 시작한다. 대진과 일반/신입 구분, 도착 순번을 담은 간결한 카드가 포인터 위쪽에 떠서 따라온다. 원래 자리는 높이를 유지하며 흐리게 표시한다.
- 행 중앙을 기준으로 앞/뒤 삽입을 구분한다. 원본 제거 후 인덱스를 따로 계산하여 안내선과 실제 저장 순서가 일치한다. 실제 높이가 다른 신입 행도 실측한다.
- 삽입 경계 아래 행들이 12px 움직이며 공간을 표시한다. 포인터가 경계 부근에 멈췄을 때 떨림을 줄이는 4px 완충 구간을 둔다.
- 놓으면 180ms 정착 애니메이션 후 700ms 이내의 색 피드백을 준다. 정착 좌표를 계산할 때 gap CSS 전환을 끄고 측정하여 일시적인 12px 편차를 방지했다.
- 자동 스크롤을 가장자리 거리와 경과 시간 기반으로 변경했다. 목록 밖 드롭, Escape, pointercancel, 포커스 상실은 취소한다. 키보드 위/아래 이동과 저장 잠금은 유지한다.
- 움직임 감소 설정에서는 이동 애니메이션을 생략하고 삽입선·색·결과 안내를 유지한다.
- 일정 상세 코트의 추가 인원 타일: 포지션을 왼쪽, 이름/소속을 오른쪽에 두는 가로형으로 변경. 기본 높이 52px. 긴 내용은 자연스럽게 높이가 늘어나며 잘리지 않는다. 코트 기본 6자리 크기는 유지했다.

## 검증

- SIDEOUT 257개 테스트 / 28개 파일 통과.
- 회원 UI 4개 테스트 통과.
- TypeScript 검사와 실제 앱 빌드 통과.
- 삽입 경계·위/아래 이동·원래 자리·목록 밖 취소·스크롤 속도 단위 테스트 추가.
- 카드 노출·저장 잠금·실제 저장 배열 순서·Escape/포인터 취소 회귀 테스트 추가.
- 실제 브라우저: 마우스 아래 이동, CDP 터치 위 이동, touchCancel, Escape, 밖에 놓기, 가장자리 자동 스크롤, 키보드 이동, reduced motion 통과.
- 위 방향 드롭의 애니메이션 종료 Y=189.656006 / 도착 행 Y=189.656250: 오차 1px 미만.
- 320/390/1024px에서 가로 넘침 없음. 추가 인원 타일 높이 모두 52px, 이름과 소속 표시 유지.
- independent read-only review: 확인된 차단 이슈 없음. 리뷰에서 제기한 정착 좌표 확인 사항도 브라우저 측정으로 확인했다.
- 디자인 detector: 대상 파일 보고 항목 없음.
- 브라우저 검증은 별도 합성 일정에서 수행했고 저장 API를 호출하지 않았다. 사용자의 연습 일정 저장 데이터는 변경하지 않았다.
