# 팀명 수정과 상태 안내 높이 정리

- 상태 안내의 상하 여백 중복을 제거했다. 공개/전원 배정 상태 모두 기본 46px, 버튼 터치 높이 44px. 보조 안내나 확대 글꼴은 필요한 만큼 높이가 늘어난다.
- 미리보기 팀명 옆 연필 버튼(44×44px)으로 이름을 입력한다. 1~40자, 앞뒤 공백 제거. 적용은 편집안만 갱신하고 상단 저장으로 확정한다.
- 팀 ID, 선수 배정, 경기 순서는 유지한다. 서버 저장의 기존 title 계약을 사용하며 공개 중 이름 수정은 숨긴다.
- 취소, 빈 이름/40자 초과 방지, 긴 이름 줄바꿈, 미저장 상태 반영을 검증했다.

## 검증
- 새 회귀 테스트 구현 전 2개 실패 확인, 구현 후 전체 275개 테스트 통과.
- TypeScript와 production build 통과, 4180 앱 서버 재시작.
- Chrome 320/390/1024px: 두 상태 높이 46px, 아이콘 44×44px 확인.
- 가상 전용 일정에서 이름 적용→저장→새로고침→상세/경기 순서 이름 확인. 선수·대진 유지. 시험 일정 이름/공개 상태 원복.
- 기존 사용자 연습 일정 2건은 전후 API 데이터 동일.
- 공개/편집/긴 이름/PC 스크린샷 직접 검토. 실제 iPhone 재검증은 수행하지 않음.

근거: browser.json, verify-browser.mjs 및 같은 폴더 PNG.
