# 공개 화면 정리 검증

## 적용
- 공개된 팀편성의 미리보기·포지션 조회·일정 상세에서 빈 타일을 숨긴다. 배정된 코트 위치는 grid 좌표로 보존하며 배정된 추가 선수는 표시한다.
- 공개 취소 후에는 기존 편집용 빈자리를 다시 표시한다. 저장 데이터는 삭제하거나 재배치하지 않는다.
- 상시 `최신 정보 불러오기`를 제거한다. 15초 조회와 포커스 재검증은 유지하고 충돌·저장 후 조회 실패 시에만 복구 버튼을 제공한다. 미저장 변경을 버리는 복구에는 확인을 받는다.
- 공개 취소 성공과 자동 갱신 성공 문구를 지속적인 오류 배너로 표시하지 않는다. 실제 실패 안내는 유지한다.

## 검증
- 변경 전 회귀 테스트: 새 기대값에서 4개 실패 확인.
- 변경 후 SIDEOUT 전체: 28 파일, 271 테스트 통과.
- TypeScript와 production build 통과. 4180 서버 재시작 완료.
- Chrome 320/390px: 공개 미리보기·포지션·상세에서 빈자리 없음, 코트 좌표 유지, 가로 넘침 없음.
- 전용 가상 일정에서 공개 취소→빈자리 편집 복원→재공개→빈자리 숨김 확인. 성공 문구가 남지 않음을 확인.
- 기존 연습 일정 2건의 전후 API 응답 동일. 사용자 데이터 보존.
- 스크린샷 preview-390.png, detail-320.png, withdrawn.png 직접 확인.
- 실제 iPhone 터치는 이번 검증에 포함하지 않음.
