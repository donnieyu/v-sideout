# 미신청 회원 필터 간소화

## 적용

승인된 제안대로 검색창 오른쪽에 44×44px 필터 버튼 하나를 배치했다. 기존 소속 모임·포지션 버튼 행과 바깥 초기화를 제거해 모바일에서 약 44px의 세로 공간을 선수 목록에 돌려준다. 미신청 회원 탭 자체에는 인원 수를 표시하지 않는다. 필터 버튼의 작은 숫자는 선택된 조건 개수이다.

하나의 팝업에 소속 모임과 포지션을 함께 배치한다. 항목 전체를 누르면 선택되며 옅은 배경과 체크 아이콘으로 표시한다. 각 항목의 터치 높이는 최소 44px이고 복수 선택이 가능하다. 초기화와 닫기는 팝업 상단에 둔다. 초기화는 검색어를 지우지 않고 필터 조건만 해제한다.

팝업은 화면 높이와 사용 가능한 공간 안에서 열리며 내부 스크롤을 지원한다. 긴 모임명은 줄바꿈한다. 모임 목록이 길어지면 해당 영역도 스크롤된다. Escape 또는 닫기 버튼으로 닫으면 필터 버튼으로 초점을 돌려준다. 외부 클릭의 기본 초점 이동은 유지한다.

이름·소속 검색 AND 모임 필터 AND 주/부 포지션 필터의 기존 규칙은 변경하지 않았다. 같은 필터 안에서는 복수 선택을 OR로 처리한다. 참가 신청·팀 저장 로직은 변경하지 않았다.

## 검증

- 관련 UI 테스트 20개 통과. 필터 열기, 복합 조건, 선택 상태 유지, 초기화, Escape, 미신청자 확인 흐름 포함.
- TypeScript 검사 및 프로덕션 빌드 성공.
- 브라우저 320×844, 390×844, 1024×844, 390×480 확인.
- 검색창/필터 같은 행, 44px 버튼, 선택 숫자 위치, 팝업 화면 내 배치, 복수 모임·포지션과 검색 조합, 초기화의 검색어 보존, Escape 초점 복귀 확인.
- 브라우저 오류 및 가로 페이지 넘침 없음. 검증 전후 저장 데이터 동일. 이번 검증은 데이터 쓰기 없이 실행.
- 실제 iPhone 키보드 검증은 하지 않았으며 390×480은 짧은 뷰포트 모사다.

증거: `browser.json`, `verify-browser.mjs`, `closed-*.png`, `open-*.png`.
