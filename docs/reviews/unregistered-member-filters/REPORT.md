# 미신청 회원 전체 조회 및 필터

## 최종 사용자 결정
- 모든 활성 미신청 회원을 후보로 조회한다. 취소했던 회원도 같은 미신청 회원으로 취급한다.
- 취소 이력은 화면·확인 문구·후보 응답에 추가하지 않는다.
- 공개 취소 후 운영진의 팀편성 편집 경로에서 취소자와 미신청 회원을 추가할 수 있다.
- 공개 중 팀편성 쓰기 잠금은 유지한다. 회원 직접 신청과 기존 명단 편집 경로의 접수 정책은 이번 변경 대상이 아니다.

## 구현
- 탭의 회원 수 제거. 빈 목록일 때도 미신청 탭을 열 수 있다.
- 이름/소속 검색 + 모임 복수 선택 + 주·부 포지션 복수 선택. 필터 간 AND, 각 필터 선택 항목 간 OR.
- 필터는 미신청 탭에만 적용. 선택칩 한 줄, 펼침 목록 내부 스크롤, 필터별 전체/전체 필터 초기화. 탭 검색이 다른 참가 상태로 확장되지 않게 한다.
- 주포지션 미등록은 별도 선택 가능. 부포지션만 비어 있는 정상 주포지션 회원은 미등록 결과에 포함하지 않는다.
- 이미 배정된 선수 및 비활성 회원은 후보에서 제외. 기본 신청자 탭의 주→부→다른 포지션 그룹 규칙 유지.
- 후보 선택 시 참석 의사 확인. 저장 시 confirmedMemberIds를 검증하여 등록과 편성을 같은 원자적 쓰기로 반영한다.
- 재등록은 신청 마감·소속 우선·정원 규칙을 따른다. 기존 공개 스냅샷은 재공개까지 유지한다.

## 검증
- UI 변경 전 관련 회귀 테스트 실패 확인. 서버 정책 변경 전 관련 테스트 실패 확인.
- 전체 282 테스트 통과, TypeScript 및 production build 성공.
- 320/390/1024px Chrome: 전체 후보 수, 숫자 없는 탭, 복수 모임+포지션+검색 조합, 가로 넘침 없음.
- 전용 가상 일정: 사전 취소→공개→공개 취소→확인 취소(변경 없음)→추가 자리 배정→등록 및 초안 저장→재조회 성공.
- 공개 중 추가 금지, 일반 회원 쓰기 금지, 확인 누락 거절 및 부분 쓰기 방지, 원본 공개 스냅샷 유지 검증.
- 사용자 연습 일정 2건의 전후 API 응답 동일. 실제 iPhone 조작은 미검증.
- 별도 검증 fixture ID와 상세 결과는 browser.json, 재현은 verify-browser.mjs.
- 첫 브라우저 실행은 배정 대상 선택 없이 교체를 기대한 검증 스크립트 오류로 중단. 명시적으로 배정된 자리를 선택하도록 수정한 뒤 전체 흐름 통과.
