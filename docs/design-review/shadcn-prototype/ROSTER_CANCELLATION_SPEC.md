# 명단 확인과 운영진 신청 취소 — 이번 프로토타입 구현 기준

## 목적과 범위

마스터와 해당 모임 권한이 있는 운영진이 회차별 명단에서 회원을 추가하거나 신청·대기 등록을 취소한다. 일반 회원에게는 자기 모임의 소속 회원 이름과 게스트 인원수만 보인다. 이 문서는 `shadcn-prototype`의 메모리 기반 샘플 상태에 적용하며 실제 계정 인증이나 서버 저장을 뜻하지 않는다.

## 명단과 화면

- 운영진 명단은 `소속 회원 → 게스트 → 대기자` 순서다. 각 그룹의 인원수를 표시한다.
- 소속 회원은 이름만 있는 촘촘한 타일로, 게스트와 대기자는 이름과 작은 소속 글씨가 있는 타일로 표시한다. 두 열을 기본으로 하고 폭이 부족하거나 글자를 키우면 한 열로 내려간다.
- 운영진 타일에는 `취소` 버튼을 직접 표시한다. 한 가지 동작을 숨기는 `⋯` 메뉴는 사용하지 않는다. 버튼의 접근성 이름은 대상과 신청·대기 상태를 포함한다. 확인창에 대상 이름을 넣고, 공개 팀에 배정된 사람은 해당 공개 자리가 비워진다는 사실도 보여준다.
- 기존 `확인` 버튼이 있는 하단 공간에 운영진용 `참가자 추가`와 `닫기`를 나란히 둔다. 복수 추가 화면의 체크박스 행은 유지한다.
- 일반 회원에게 타일 취소 버튼과 추가 버튼을 제공하지 않는다. 게스트 실명과 소속을 공개하지 않고 인원수만 표시한다.

## 취소 상태 전이

| 현재 상태 | 명단 처리 | 팀편성 처리 |
| --- | --- | --- |
| 신청, 미배정 | 신청자에서 제외 | 다른 선수와 팀은 그대로 |
| 신청, 초안 배정 | 신청자에서 제외 | 취소 선수만 초안에서 제거 |
| 신청, 공개 배정 | 신청자에서 제외 | 취소 선수만 초안과 공개본에서 제거 |
| 대기, 미배정 | 대기자에서 제외 | 다른 선수와 팀은 그대로 |
| 대기 후 공개 배정 | 신청자로 승격된 현재 표시에서 제외 | 취소 선수만 초안과 공개본에서 제거 |

기본 샘플 신청자는 페이지 상태에서 재생성되므로 회차별 제외 기록으로 재등장을 막는다. 수동 추가된 명단은 해당 회차 항목을 제거한다. 본인이 취소 대상일 때는 `applied`/`waiting` 상태도 지운다. 다른 선수의 초안 수정은 공개하지 않고 대진 순서도 새로 만들지 않는다. 공개본에 빈 자리가 생기면 운영진이 팀편성 수정에서 대체 선수를 배정한다.

기본 공개 팀편성을 샘플에서 다시 구성할 때도 현재 회차의 제외 기록과 본인 신청 상태를 함께 적용한다. 다른 회원을 취소한 직후 미신청자인 본인이 공개 팀·명단에 되살아나서는 안 된다. 반대로 공개 전 운영진이 본인의 신청을 취소한 뒤 본인이 직접 다시 신청하면, 그 회차의 제외 기록에서 본인을 지우고 신청자·인원수에 다시 포함한다. 공개 후 본인 재등록은 기존 규칙대로 대기 등록이며, 공개 팀에 자동 복귀하지 않는다.

취소는 시작 전의 등록된 회차에서만, 해당 모임을 관리할 권한으로 실행한다. 과거·이미 시작한 운동에는 이 명단의 취소 기능을 제공하지 않는다. 회원 계정이나 다른 회차 기록은 변경하지 않는다.

취소된 회원을 운영진이 다시 추가하면, 그 시점의 접수 규칙에 따라 일반 신청자 또는 대기자로 들어간다. 공개 이후에는 대기자로 추가되며, 기존 공개 팀에 자동 복귀하지 않는다. 취소 직후와 재추가 후 신청 인원, 대기 명단, 팀편성 후보, 열람 권한을 같은 회차 상태에서 계산한다.

## 수용 조건과 검증

1. 기본 샘플·수동 추가 신청자를 취소한 뒤 명단을 닫았다 다시 열어도 재등장하지 않는다.
2. 신청자와 대기자, 미배정 신청자 수가 같은 회원 집합을 기준으로 갱신된다.
3. 초안과 공개본에서 취소 선수만 사라지고, 공개 전 다른 초안 변경은 공개되지 않는다.
4. 공개 후 재추가는 대기로 들어가며 공개 팀에 자동 배정되지 않는다.
5. 권한 없는 회원·다른 모임 운영자·운동 시작 후에는 취소 동작이 없다.
6. 취소 버튼과 확인창은 키보드·터치로 사용할 수 있고, 모바일 320/390px에서 명단 타일과 하단 버튼이 화면 밖으로 넘치지 않는다.
7. 공개 후 미신청 상태에서 다른 회원을 취소해도 본인이 명단·공개 팀에 나타나지 않고, 공개본 열람 권한이 생기지 않는다.
8. 공개 전 운영진 취소 후 본인이 재신청하면 명단과 인원수가 다시 증가하고, 본인 취소도 정상 동작한다.

독립 검토 대상은 이 문서, 변경한 소스, 검사 결과와 모바일 화면 기록이다. `web/` 제품 구현과 실제 로그인·서버 권한·저장은 이 검토 범위에 포함되지 않는다.
