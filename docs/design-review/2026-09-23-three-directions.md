## 인원 표시 제안

기준 단계까지 채워진 기록을 작은 완료 표식으로 남기고 현재 추가 구간만 바에 표시한다. 표시 단계가 바뀌어도 완료한 18명이 사라지지 않는다.

| 현재 인원 | 완료 표시 | 현재 구간 |
|---|---|---|
| 0–17 | 없음 | 0 → 18 |
| 18–20 | 18 ✓ | 18 → 21 |
| 21–23 | 18 ✓, 21 ✓ | 21 → 24 |
| 24–27 | 18 ✓, 21 ✓, 24 ✓ | 24 → 28 |
| 28 이상 | 네 단계 모두 완료 | 바 대신 추가 인원 +n명 |

새 구간이 시작할 때 0부터 표현되는 것은 그 구간의 추가 인원이다. 전체 신청 인원은 항상 크게 표시하며 '몇 명 달성 / 다음 기준까지 몇 명'을 함께 표시한다. 정원 제한·후보 인원·운영자에 의한 팀 배정은 별도 상태이며 단계 표시와 연결해 자동 결정하지 않는다.
