# SIDEOUT 팀편성 최종 화면 및 일정 상세 연결

확정: 2026-09-26 사용자 승인. 현재 B를 최종 방향으로 사용하며 A는 참고자료로 보관한다.

## 확정한 화면

- 포지션별 연속 배정: 세터 → 레프트 → 센터 → 라이트.
- A·B·C(필요 시 D)는 열, 같은 팀의 자리는 세로로 표시한다.
- 선수 타일은 모바일 배정판과 선수 풀이 함께 보이도록 압축한다. 배정된 타일의 이름을 누르면 교체할 자리를 선택하고, 별도 X 버튼을 누르면 확인창 없이 즉시 배정을 해제한다. 빈 타일은 전체를 눌러 선택한다.
- 배정하면 현재 자리 다음의 빈자리로 순환한다. 다음 포지션 이동은 버튼으로 명시한다.
- 상단 배정판·검색·필터와 하단 내비게이션을 유지하고 선수 목록만 내부 스크롤한다.
- 현재 포지션에서 팀별 배정을 함께 비교한다. 전체 팀에서 코트/행 보기를 전환한다.
- 세 팀 기준 라이트는 팀마다 두 자리다. 첫째 자리는 코트의 여섯 명 안에, 둘째 자리는 코트 밖 `추가 인원`에 둔다. 18명이라도 둘째 자리는 빈 상태로 보이며, 팀 인원은 실제 배정 인원만 센다.
- 추가 인원은 코트보다 차분한 별도 배경에 배치하고 타일에는 `교대` 대신 배정 포지션(기본 `라이트 2`, 수동 추가 선수는 해당 선수 포지션)을 쓴다. 이 영역은 경기별 교대 순서를 지정하지 않는다.
- 편집 화면의 `저장`은 연한 파랑의 보조 동작, 조건을 만족했을 때 활성화되는 `공개`는 진한 파랑의 주요 동작으로 구분한다. 모바일 하단의 `이전`·`다음`은 동일한 외곽선 버튼이며 세터와 라이트 사이에서도 순환한다. 가운데 `팀 구성`은 전체 팀의 코트/행 보기, 팀 추가와 추가 선수 자리 관리를 여는 진입점이다.
- 한 팀에만 수동 추가 자리가 있어도 해당 자리를 눌러 후보를 배정할 수 있다. 다른 팀에 같은 자리가 없으면 `자리 없음`으로 표시한다.
- 자율 배치는 후속 검토. AI·실력 투표·LLM 헬퍼는 이번 구현 범위가 아니다.

## 연결한 범위

현재 검토 앱 `/weekend/a-shadcn/`의 일정 상세 → 팀편성 수정 → 전체 화면 배정 작업 → 초안 저장/저장/공개 → 같은 일정 상세로 복귀한다. 독립 `/weekend/allocation-ab/`도 바깥 스크롤 없는 작업 영역으로 정리했다.

권한 및 공개 여부는 기존 일정 상세 판단을 따른다. 해당 일정의 신청자·대기자·이미 배정한 사람을 후보로 전달하며 마스터에게는 기존 모든 회원 후보 범위를 유지한다. 프로필의 주·부 포지션과 실제 배정 포지션은 구분한다. 저장된 자리 식별자를 보존하여 교대 선수가 재열기 때 정규 자리로 이동하지 않도록 한다.

초안 저장은 기존 공개본을 교체하지 않는다. 공개 확인 후에 공개본을 교체한다. 변경을 취소할 때 확인창을 띄우며, 브라우저 새로고침/이탈의 미저장 변경 경고를 제공한다. 팀 추가(최대 4), 빈 팀 삭제, 교대 자리 추가, 주·부 포지션 자동 배치를 연결했다.

공개는 현재 신청자 전원이 어느 팀이든 배정된 때에만 활성화한다. 빈 추가 선수 자리는 공개를 막지 않으며 대기자·미신청 회원도 전원 배정 조건에 넣지 않는다. 초안 저장은 미배정 신청자가 있어도 허용한다. UI 비활성화와 별개로 명단 상태 명령에서도 같은 공개 조건을 확인한다.

- 후보 목록 scrollTop 547px 이동 시 편집기 top 0 및 배정판 top 약 154px 유지 확인.
- 디자인 기계 검사에서 대상 파일 추가 발견 없음.

## 남아 있는 제품 연결

이번 연결은 로컬 디자인 검토 앱이다. `web/`의 운영 앱 및 배포 사이트에는 아직 이 편집기를 이식하지 않았다. 검토 앱의 초안/공개 상태는 메모리에만 존재하며 새로고침하면 초기화된다. 실제 로그인, 서버 권한 검증, DB 저장, 여러 운영자의 동시 수정 충돌 처리는 운영 앱 적용 단계의 작업이다. 실기기 터치·소프트 키보드 검증은 별도 필요하다.

## 일정 정보와 팀편성 편집 분리 (2026-09-26)
- 조회 상세: 고정된 모임·날짜 문맥 아래 일정 정보/일정 수정, 별도 구분선 아래 팀편성/팀편성 수정.
- 일정 수정: 시간·장소·신청 설정·공지에 한정. 참석 동작과 팀편성·경기 순서 숨김. 같은 작업 영역에 취소/저장.
- 팀편성 수정: 기존 확정 배치 UI를 전용 화면으로 사용. 브라우저 뒤로 가기, 취소/저장 후 같은 상세 팀편성 영역으로 복귀. 미저장 배정 이탈 확인.
- 경기 순서는 선수 배정과 독립된 팀 수별 템플릿. 편성이 완성되면 결과와 함께 표시. 3팀은 공유된 예시의 반복 순서, 4팀은 검토용 라운드로빈 기본안이며 확정 운영 순서는 미확정. 3팀은 기존 예시의 경기별 시간을 유지하며, 4팀은 대진 순서만 표시. 시간은 모임별 운영 템플릿 확정 필요.
- 현재 로컬 검토용 목업이며 데이터는 메모리 상태. 실제 서버 저장 및 직접 URL로 편집 세션 복원은 미구현.

### 공통 앱 레이아웃 보완 (2026-09-26)
- 일정 편집 취소는 변경 여부와 관계없이 사용 가능. 기존의 변경 전 비활성화 결정을 이번 요청으로 대체. 저장된 준비 상태의 취소도 편집 초기화가 아닌 홈 복귀.
- 팀편성 편집은 SIDEOUT의 공통 사이드바/모바일 헤더, 모임·날짜, 상세 경로를 유지하는 자식 화면. 전역 전체 화면 덮기 및 앱 탐색 숨김 제거.
- 편집기 안에서 배치판과 하단 이동 버튼은 유지하고 선수 풀 내부 스크롤. 낮은 화면은 간격을 줄이며 극히 낮은 화면은 페이지 스크롤을 허용하여 조작 영역이 사라지지 않게 함.
