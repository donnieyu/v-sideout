# 일정 v4 실제 화면 적용

2026-10-09 · promotion-p1 · 사용자 승인 후 실제 4180 앱에 적용. 외부 공개 사이트 배포/메인 병합은 이번 범위에 포함하지 않음.

## 적용

- 공통 SIDEOUT 헤더, 모바일 하단 메뉴와 통합 계정 항목. 편집기에서는 기존 하단 조작을 보존하며 메뉴를 헤더에 유지.
- 날짜 바깥 그룹 + 상태/마감·모임/운동 안내·장소·입장/시작/종료·명단/인원 바·신청 행동을 카드에서 제공. 관리자 일정 관리 진입 유지.
- 참석 신청 → 같은 위치 참석 취소. 공개 열람 허용 → 팀편성·경기 순서. 마감 시각은 신청 완료 상태에서도 유지.
- 명단 확인으로 명칭 통일. 신청자·대기자 탭과 내부 스크롤. 기존 명단 추가/취소/공개 취소 동작, 읽기 범위 유지. 다른 모임 회원은 명단 수와 열람 제한만 확인.
- 운동 안내에 저장된 자유 공지와 실제 입장/장소 표시. DTO에 없는 준비물/시설 정책을 임의 생성하지 않음.
- 팀별 과한 색상 제거, 중립 카드와 작은 공개/내 팀 표시. 코트/행, 상세 일정 수정·팀 수정·경기 수정과 경기 표 유지. 경기 순서 바로가기 없음.
- 인원 바는 다음 18/21/24/28 기준까지 채움. 서버 정원/참가 권한 규칙은 변경하지 않음.

## 검증

- 전체 SIDEOUT 33개 파일 / 361개 테스트, 인증 UI 4개 테스트.
- 타입 검사, 변경 파일 ESLint, 빌드. 결과 파일: sideout-tests.txt, member-tests.txt, types.txt, lint.txt, build.txt.
- 별도 읽기 전용 검토에서 명단 중복 복원/본문 이동 시 편집 보호 해제 2건 발견. 실패 재현(review-red.txt, guard-red.txt) 후 수정; 검토자 재실행 14개 통과.
- 320/390/1024px 브라우저: 가로 넘침 없음. 빈 대기자 탭 선택 가능. 390px 명단 92dvh, 이름 13px/500, 취소 및 하단 버튼 44px. 내부 스크롤과 오버레이 동안 메뉴 숨김 확인. 실제 값은 browser-metrics.json.
- 공개 연습 일정의 코트/행 토글, 기존 18명과 경기 순서, 공개 편집 읽기 전용·저장 비활성, 64px 헤더 + 780px 편집 본문(844px 화면) 확인.
- 기존 앱 데이터를 읽어 화면만 검증했으며 신청·취소·배정·공개 데이터 쓰기를 수행하지 않음. 최종 빌드 후 기존 .wrangler/sideout-p1 저장소로 서버 재시작.
- 기계적 디자인 검사 경고 1건: 기존 미사용 .tabs 버튼의 3px 하단선(기존 CSS 16행). 새 읽기 화면에서 해당 스타일을 사용하지 않음. 명단의 원격 권한 취소 effect는 기존 안전 동작을 위한 좁은 lint 예외와 이유를 코드에 기록.
