# 일정 홈 색상 개선 적용

2026-10-09. 사용자가 승인한 실제 앱 레이아웃 기반 이미지 `approved-color-actual-layout.png`가 기준이다. 이전 3열 목업의 배치로 되돌리지 않았다.

- 홈 상태 뱃지: 접수 파랑, 신청 완료/공개 초록, 대기 황토색, 기타 회색. 상태 문구는 서버 participation 계약을 우선 사용한다.
- 모임 아이콘: 작은 단색 이니셜. 색은 모임 ID로 구분하며 로고 업로드 기능은 추가하지 않았다. 상세의 동일한 아이콘도 같은 색을 사용한다.
- 카드 상단 2px 선과 뱃지 배경은 가상 요소로 그려 기존 카드 높이를 보존한다.
- 선택 필터 남색/흰 글씨, 미선택 흰 바탕. 기존 신청/취소, 명단, 안내, 일정 관리 기능 유지.

## 확인

- 변경 전 상태 회귀 테스트 3건 실패를 확인한 뒤 수정. 상태·홈·읽기 화면 3개 파일 39개 테스트 통과.
- TypeScript 및 변경한 TSX 파일 ESLint 통과. 빌드 통과 (`color-build.txt`).
- 390px: 카드 높이 409.0859375px, 시작 위치 321.984375px, 상태 줄 18.59375px로 변경 전과 동일.
- 320/390/1024px: 가로 넘침 및 상태-마감 문구 겹침 없음 (`color-browser-metrics.json`).
- 실제 모임 필터 선택 시 해당 모임만 표시, 남색 배경/흰 글씨 확인.
- 브라우저에서 신청 완료와 대기 접수 상태 확인. 공개/접수 종료 등은 기존/회귀 테스트로 확인했으며 해당 상태를 만들기 위해 사용자 데이터를 변경하지 않았다.
- 텍스트 색 대비: 정보 6.04, 완료 5.92, 대기 4.85, 아이콘 청록 4.58/회갈색 4.72, 선택 필터 9.09. 중립 뱃지는 대비 보완을 위해 #5e6e7e 사용.
- 4180 서버를 기존 로컬 저장소로 재시작. 실제 iPhone 터치 검증 및 메인 병합/외부 배포는 이번 범위에 포함되지 않는다.
