# 일정 홈 고정 영역과 목록 스크롤 — 2026-10-09

## 적용 범위

- SIDEOUT 헤더, 모임 필터, 주 이동, 날짜 요약을 고정하고 일정 목록만 세로 스크롤한다.
- 요일과 날짜를 한 줄로 표시하고 일정 유무 점을 유지한다. 날짜 요약은 기존처럼 비대화형이다.
- 주·필터 직접 변경은 목록 맨 위로 이동한다. 상세 화면 왕복은 회원·주·필터별 목록 위치를 복원한다.
- 자동 조회 갱신과 명단 모달 닫기는 현재 목록 위치를 유지한다.
- 기존 색상, 참가·명단·안내·관리 동작과 데스크톱 시간대 레이아웃은 유지한다.

## 검증

- 관련 Vitest 4개 파일, 42개 테스트 통과. 새 스크롤 테스트는 적용 전에 3개 실패를 확인했다 (`scroll-red.txt`).
- TypeScript, 수정 소스 및 신규 테스트 대상 ESLint, 프로덕션 빌드, `git diff --check` 통과.
- 기존 로컬 DB를 보존하여 4180 서버를 재시작했으며 LAN `/home` 응답 200 확인.
- 390×844: 고정 영역 하단 208px, 날짜 요약 29px. 이전 목록 시작 약 288px 대비 약 80px 확보.
- 320×568: 목록 높이 360px, 가로 넘침 없음, 상단 버튼 최소 높이 44px.
- 1024×900: 가로 넘침 없음, 데스크톱 시간대 배치 유지.
- 실제 브라우저에서 목록 385.5px 스크롤 후 상단 위치 고정, 명단 열기/닫기 및 상세 이동/뒤로 가기 후 같은 위치 유지 확인.
- 주·모임 필터 변경 후 목록 위치 0 확인. 상세 화면의 body 스크롤은 기존대로 유지됨.
- 목록 끝에서 마지막 관리 링크 하단 727px, 플로팅 메뉴 상단 784px로 마지막 동작을 가리지 않음.
- 실기기 iPhone 확인은 이번 검증 범위에 포함하지 않았다. 테스트 과정에서 참가·명단 데이터는 변경하지 않았다.
