## 디자인 계획과 검토

- 색상: 배경 #f5f7fa, 표면 #ffffff, 본문 #1c2a3b, 보조 글자 #637389, 주요 행동 #1e3e64, 경계 #e0e6ed.
- 모임 식별: 뉴배동 파랑 #1269be / 초록 #287456, 히어로즈 검정 #181c22 / 금색 #98731f. 팀 색상은 마크와 카드 상단의 가는 선에만 적용한다.
- 글꼴: Apple SD Gothic Neo / Malgun Gothic 계열의 한글 고딕. 제목 28px, 카드 모임명 21px, 본문 13px, 보조 정보 11–12px. 기존 C안의 크기와 한 줄 제목을 유지하고 모바일에서만 자연스럽게 줄바꿈한다.
- 배치: 기존 사이드바 + 한 줄 제목과 작은 설명 + B형 필터 + 두 열의 세로 모집 카드. 화면이 좁으면 카드가 한 열로 전환된다.
- 카드 흐름: 접수 상태·마감 → 모임명 → 날짜·장소 → 입장/시작/종료 → 신청 현황 → 참석 신청·모임 공지.
- 기존안 검토: B의 큰 제목, 어두운 바탕, 긴 여백은 제거한다. C의 정보 밀도를 유지하되 가로형 카드로 돌아가지 않는다. 장식용 영문 라벨과 공통 공지 띠는 제거한다.

## 리뷰 반영

- 다른 모임도 버튼 이름은 '참석 신청'으로 동일하다. 소속에 따른 분류와 우선권은 내부 운영 정보다.
- 전체 서비스 알림은 사이드바 알림 진입점으로 모은다. 별도의 상단 바를 재도입하지 않는다.
- 모임 공지는 카드의 참석 신청 버튼 옆 아이콘에서 연다. 접근 가능한 이름과 읽지 않은 공지 표시를 제공한다.
- 신청 인원은 18 → 21 → 24 → 28 참고 단계를 유지한다. 기준 달성 표시와 추가 구간을 함께 표시하며 정원·편성 보장으로 표현하지 않는다.
- 회원 소속은 고정이며 모임 필터를 바꿔도 소속과 권한이 바뀌지 않는다.

## 회원 우선 신청과 공개 범위

- 일정에 소속 회원 우선 신청 종료 시각을 둔다. 설정 주체는 해당 모임 운영자다. 이번 목업에서 운영 설정 화면을 만들지는 않는다.
- 사용자 추가 답변에 따라 우선 기간 중에도 모두 참석 신청할 수 있다. 이 기간에 신청한 소속 회원은 팀편성 보장 대상이다.
- 타 모임·무소속 회원의 신청도 접수하며 운영자에게 신청 순서대로 보관·표시한다. 선착순 자동 편성으로 확정하지 않는다.
- 최신 답변의 '인원수만 확인 가능'을 기준으로 신청 인원은 우선 기간 여부에 관계없이 모두에게 표시한다. 이전 초안의 우선 기간 중 외부 회원에게 인원 숨김 규칙은 대체된다.
- 소속 회원은 같은 모임 소속 신청자의 이름을 확인한다. 타 모임·무소속 신청자 이름까지 공개하는 명단이 아니다. 예: 총 20명 신청, 같은 모임 소속 14명 이름 조회.
- 타 모임·무소속 회원은 팀편성이 공개되기 전 신청 명단을 조회할 수 없다.
- 우선 기간 종료 후에도 소속 회원의 같은 모임 신청자 조회 권한은 유지한다.
- 신청 명단에는 이름만 표시한다. 신청 순번·시각, 불참·미응답, 실력·주/부 포지션은 기존대로 회원 비공개다.
- 신청 명단과 최종 팀편성표는 다른 정보다. 발표 후 팀편성표를 확인하는 기존 흐름은 유지하는 것으로 제안한다.
- 실제 구현 시 비공개 데이터는 서버 응답에서 제외해야 한다. 이번 비교 목업에는 가상의 예시 정보만 사용한다.

우선 기간의 의미는 사용자 답변으로 확인 완료. 팀편성 시 '기간 내 소속 회원 신청'을 보장 대상으로 보존해야 한다. 날짜가 지나거나 타 모임 필터를 선택했다고 보장 상태가 사라져서는 안 된다. 보장 인원이 기존 팀 구성의 인원수를 초과하면 임의로 제외하지 말고 운영자가 팀 수·편성 방식 등을 조정해야 한다. 우선 기간 이후 신규 신청한 소속 회원까지 자동 보장 범위를 확대하지 않는다.

목업에서 열람 회원 예시를 뉴배동/히어로즈/무소속으로 바꿔 인원수는 유지되고 소속 회원 명단 버튼만 달라지는 것을 비교할 수 있다. 이는 화면 검토용 설정이며 실제 계정 소속 수정 기능이 아니다. 명단은 가상 이름이며 신청 순서가 노출되지 않도록 이름순으로 표시한다.

## 범위

초기에는 별도 목업만 작성했다. 이후 사용자 승인으로 실제 사이트에 적용되었다. 회원 소속·우선 기간·신청/취소·명단·편성 공개가 연결되었고 마스터 회원 정보 등록도 구현되었다. 로그인 자격 발급·실제 인증은 후속 범위다. 과거 목업 설명을 현재 기능 미구현의 근거로 사용하지 않는다.

## 후속 리뷰 반영 — 문구 축소와 신청 후 동작

- 모집 카드에서 우선 편성 규칙 설명, 전체 신청 가능 안내, 명단 공개 시점 안내를 제거한다. 규칙은 유지하고 반복 안내만 줄인다.
- 진행 바 아래에는 다음 기준까지 필요한 인원만 표시한다. 예: 17명일 때 '18명까지 1명', 20명일 때 '21명까지 1명'. 다음 단계 숫자를 나열하는 하단 문구도 제거한다. 28명 이상은 '28명 달성'과 별도의 추가 인원 표시를 유지한다.
- All 목록은 로그인 회원의 소속 모임 일정을 우선 배치한다. 그 외 모임은 운동 시작일 순으로 표시한다. 무소속은 전체를 시작일 순으로 표시한다. 특정 모임 필터는 해당 모임만 보여준다.
- 내 모임의 신청 인원 옆 버튼은 '명단 확인'으로 통일한다. 같은 모임 신청자만 이름순으로 표시하는 기존 공개 범위를 유지한다.
- 신청 전: '참석 신청'과 모임 공지 아이콘.
- 신청 후, 팀편성 공개 전: '참석 취소'와 비활성 '팀편성 확인', 모임 공지 아이콘.
- 신청 후, 팀편성 공개 후: '팀편성 확인' 활성화. 운영자 초안 저장만으로 공개하지 않는다.
- 마감 후에는 기존대로 '참석 취소'가 비활성화되며, 미신청 회원은 후보 신청 가능하다.
- 공개된 편성 예시는 공개 시점의 목록으로 보존한다. 공개 이후 신청자가 늘었다고 자동으로 팀에 넣지 않는다.
- 화면 비교 설정에서 열람 회원 소속, 신청 인원, 팀편성 공개 여부, 신청 마감 여부를 바꿔 동작을 확인할 수 있다. 실제 계정·신청·팀편성 기록에는 반영되지 않는다.
