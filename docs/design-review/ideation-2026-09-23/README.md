신청·취소 시뮬레이션은 뉴배동 9/27 회차에만 연결했다. 다른 회차의 버튼, 계정·기타 메뉴는 비교 범위 안내를 표시한다. 팀편성표는 공개 상태의 표시 방식을 보여주는 일부 샘플 인원이다. 서버 통신·계정·저장 기능은 없으며 실제 기능 완성으로 취급하지 않는다.

1. 동일 강도의 카드에서 내 운동의 우선순위를 더 명확하게 만들기.

## 세 안의 방향 계약

공통: 운영 목적의 화면, 새 정책 없음, 제거된 반복 설명 없음, 접근성 이름·44px 동작 영역·focus-visible·native dialog의 포커스 복귀 유지. 사소한 픽셀 조정보다 구조 비교가 우선.

A 내 운동 중심 — 핵심은 날짜표+회차정보+참석행동을 가로로 연결한 첫 회차. 배경 #f3f6fa, 본문 #192e43, 보조 #617488, 행동 #234e79, 모임색 녹색/파랑 및 검정/금색. 작은 화면은 날짜와 요약을 유지하고 행동을 아래로. 대표 기억: ‘이번 주 내 운동과 신청이 먼저 보인다.’ 첫 카드 아래 회차는 같은 정보로 작은 카드가 된다.

B 일정 비교 중심 — 핵심은 소속 모임별 그룹 안에서 정렬된 날짜·시간·인원·행동. 반복 회차의 모임명을 그룹에 올린다. 좁은 남색 메뉴 레일로 비교 너비 확보. 모바일은 행 하단의 행동을 유지한다. 대표 기억: ‘일정표를 훑듯 여러 운동을 비교한다.’ 글로벌 날짜 순서를 위해 내 모임 우선을 깨지 않는다.

C 목록과 상세 연결 — 핵심은 왼쪽 일정 선택과 오른쪽 상세 패널. 정보/공지/명단의 표시 공간을 공유하고 행동은 패널 하단에 남긴다. 모바일은 목록에서 상세 시트로 전환. 대표 기억: ‘운동을 선택하고 그 안에서 확인한다.’ 외부 모임 선택 시 명단 탭을 제공하지 않는다.

타입: 제품과 같은 한국어 산세리프 스택. 제목28px, 모임명22px, 본문/동작13–15px, 보조12px 중심. 날짜 숫자만 의미상 강조한다. 색만 다른 세 안이 아니라 정보 배치·첫 화면의 중심·모바일 동선이 다르다.

## 추천과 조합

현재 한 모임 중심의 주간 반복 이용에는 A 추천. A의 첫 운동 + B의 압축된 다음 일정 + C의 모바일 상세 시트를 조합할 수 있다. 이 조합은 아직 별도 네 번째 목업으로 확정하지 않았다. 여러 일정을 비교하는 사용이 많아지면 B가 대안. C 전체는 상세 탐색이 잦을 때 적합하지만 선택 단계를 추가한다. 효과는 사용자 검증 전 가설이다.

운영 화면은 이번에 구현하지 않았다. A의 회차/공개 행동 묶음, B의 참가자 정렬 열, C의 선수/코트 문맥 패널로 확장 가능하며 기존 배정 권한·우선 보장·후보·임시 인원 규칙은 바뀌지 않는다.
