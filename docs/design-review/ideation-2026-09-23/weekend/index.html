SIDEOUT, 반복되는 주말을 어떻게 보여줄까요?

같은 다섯 모임, 서로 다른 세 가지 구조. 날짜·시간순으로 비교하고, 내 모임은 표시로 구분합니다.

선택 전 목업 · 기준일 2026.9.23 · 신청·인원·마감·공지는 샘플입니다. 운영 사이트에는 적용하지 않았습니다.

선택 안을 단독으로 열기
A · 주말 달력모임명 → 정보·공지·명단 / 신청 후 → 팀 확인
메뉴와 상세 화면은 이렇게 연결했습니다

모임 홈에 운동 일정·신청을 모으고, ‘신청한 운동만’으로 내 신청을 확인합니다. 팀편성은 별도 메뉴로 유지합니다. 모임 공간은 게시판·이벤트처럼 한 회차를 넘어 이어지는 콘텐츠의 자리입니다.

모임명 → 운동 상세: 정보 / 공지 / 명단. 인원 옆 ‘명단 확인’도 이 탭으로 연결되며 별도 팝업을 반복하지 않습니다. ‘팀편성 확인’은 입장·운동 일정 + 팀 명단 + 경기 대진 순서를 담은 당일 화면으로 연결됩니다.

팀 확인 흐름은 위에서 ‘팀 공개 후’를 선택한 뒤 뉴배동에서 확인하세요. 타 모임은 공개 전 인원수만 보이고, 명단 탭을 제공하지 않습니다. 마감 전의 대표 상태를 비교하는 화면이며 실제 서버에는 저장하지 않습니다.

장단점과 추천 조합
구조잘하는 일감수할 점
A 주말 달력토·일과 오전·오후의 선택지 비교소수 모임일 때 빈 공간. 모바일은 시간순 목록으로 전환
B 날짜별 목록두 모임부터 다섯 모임까지 간결한 신청일정 사이 빈 시간은 표현하지 않음
C 월 달력오늘·이번 주 위치와 날짜 선택평일 빈칸이 크고, 다른 날 비교는 클릭 필요

B의 목록 + 상단 오늘 표시를 기본으로 추천합니다. A는 여러 모임의 주말을 비교하는 대안으로, C는 과거·여러 주의 회차 탐색이 필요할 때 어울립니다. 정렬 변경과 메뉴 통합은 이번 비교 제안이며 실제 제품은 아직 변경하지 않았습니다.

뉴배동·히어로즈 외 세 모임의 시간·장소는 사용자 제공값입니다. 등록을 가정했을 뿐 실제 앱 등록 여부를 뜻하지 않습니다. 경기 대진은 표시 방식의 예시이며 편집·자동 생성 기능을 구현한 것은 아닙니다.
