# SIDEOUT 주말 운동 구조 비교

2026-09-23 후속 탐색. 사용자 최신 설명을 반영한 **선택 전 목업**, 실제 사이트에는 미적용.

## 방향과 공통 조건

Operate 화면. 매주 반복되는 주말 운동 5개(토3/일2)를 탐색하고 신청하는 것이 홈의 일이다. 고정 장소와 입장·운동 시간은 회차 상세를 원본으로 보고 팀편성 화면에서도 같은 데이터를 사용한다.

- 기존 C의 차분한 색·한글 제목·밀도 유지. 배경 #f3f6fa, 잉크 #192e43, 보조 #617488, 행동 #234e79, 뉴배동 #24765d, 히어로즈 #8b6a28. 아스팍·런업·더브이의 식별 색은 목업용 임시 색이며 실제 브랜드 색을 확인한 것은 아니다.
- 한국어 시스템 산세리프는 기존 UI와 이어 사용. 제목 28px, 모임명 18px, 본문 14px, 보조 12px. 좌측 정렬, 날짜와 시간의 세로 기준선으로 비교한다.
- A 주말 달력: 위에는 오늘을 포함한 한 주, 아래 토/일 두 열과 오전·오후 구역. 겹치는 오후 운동도 겹치지 않는 타일로 나란히 비교한다. 모바일은 날짜별 시간순 목록으로 적응한다.
- B 날짜별 목록: 날짜 → 시작 시간 → 타일, 빈 시간은 생략. 다섯 모임의 행동을 적은 높이에서 비교한다.
- C 월 달력: 오늘/선택일/모집이 열린 날짜를 구분. 선택한 날의 목록을 옆에 둔다. 월 전체 위치의 장점을 확인하고 평일 빈칸 비용도 비교한다.

이전 C는 목록+상세 패널이었다. 이번 C가 실제 월 달력이다. 단순 색상 교체가 아니라 요일·시간대 구역/날짜 그룹/월간 탐색으로 정보 구조를 바꾼다.

## 최신 요청으로 달라진 탐색 조건

기존 '내 모임 우선' 정렬 대신 **이번 세 비교안은 모두 날짜·시작시간 순**이다. 비교 변수 통제를 위한 제안이며, 제품의 정렬 정책은 선택 전까지 바꾸지 않는다. 내 모임은 녹색 '내 모임' 표시와 필터로 찾는다.

기준일 2026-09-23 수요일, 이번 주 9/21–27. 뉴배동 9/27 12:30 입장, 13:00–17:00 운동. 히어로즈 9/26 13:30 입장, 14:00–18:00 운동. 둘 다 양강초등학교 체육관. 후속 답변으로 아스팍 토요일 08:00–13:00 궁산다목적체육관, 런업 토요일 13:00–18:00 삼성중학교, 더브이 일요일 13:00–18:00 삼성중학교를 확인했다. 세 모임도 시작 시각은 입장 30분 후다. 인원·공지·신청 마감 시각은 여전히 샘플이다. 실제 등록 여부를 가정하지 않도록 비교 도구에서 '뉴배동·히어로즈만 / 5개 모임'을 바꿀 수 있다. 미래 회차를 매주 자동 모집하는 정책을 추가하지 않는다.

## 정보 구조 제안

- 모임 홈: 운동 일정 + 신청, '신청한 운동만' 필터로 내 신청 흡수. 기존 독립 운동 일정·내 신청 메뉴는 중복 업무가 없어 통합 제안.
- 팀편성: 공개 운동 선택 → 운동 당일 전용 화면. 입장/몸풀기/시작/종료, 팀 명단, 경기 순서. 홈의 팀편성 확인도 같은 화면으로 이동.
- 회차 상세: 정보 / 공지 / 명단. 홈 인원 옆 '명단'은 같은 상세의 명단 탭으로 이동하며 별도 명단 오버레이는 만들지 않는다. 공지도 상세의 공지 탭 한 곳으로 연결한다.
- 모임 소식: 회차 공지만으로는 독립 메뉴가 필요하지 않다. 기존 게시판/이벤트/댓글처럼 여러 회차에 걸쳐 유지하는 콘텐츠에는 독립 목적이 있으므로 '모임 공간'에 모으는 안을 제시한다. 기능 삭제가 아니다. 목업은 이 입구와 설명만 포함한다.
- 계정/서비스 알림은 사이드바 하단. 모바일은 접이식 메뉴.

## 상세와 팀편성의 연결

홈 타일 제목 → 회차 상세(정보/공지/명단). 홈 '팀편성 확인' → 회차 팀편성. 상세에서도 같은 팀편성 화면으로 이동. 팀편성의 '운동 정보'는 동일 회차 상세로 복귀한다. 두 화면은 동일 회차 객체의 날짜/장소/시간을 참조한다. 명단 탭은 소속 회원에게만 보이고 같은 소속 이름만 제시한다. 공개 팀은 배정 결과만 보여준다.

경기 순서는 사용자 후속 답변에서 **팀 간 대진의 순서**로 확인되었다. 팀편성 화면에서의 표시 방식을 제안한다. 자동 대진/점수/타이머/개인 교대 순서 관리까지 제안하지 않는다. 목업의 A–B/B–C/C–A는 수동 입력을 상정한 표시 예시이며 실제 편성 결과가 아니다.

## 목업 범위와 검증

브라우저 안에서만 신청·취소/필터/날짜 선택/정보·공지·명단/공개 팀 확인을 시뮬레이션한다. 마감 전 신청 전/신청 후/공개 후 대표 상태 비교. 전체 인원과 소속 회원 명단은 다르다. 평가·주/부 포지션·신청순서·불참 명단은 넣지 않는다. 후보와 마감 후 취소 등의 기존 로직은 변경하지 않았으며 이번 목업에서 모든 상태를 구현한 것은 아니다.

실제 API/로그인/계정 발급/회원 권한 검증과 상세 QA는 범위 밖이다. 저장·배포하지 않는다. 브라우저 화면 확인은 비교가 가능한지와 레이아웃의 큰 문제에 한정한다.


## 화면 확인 기록
