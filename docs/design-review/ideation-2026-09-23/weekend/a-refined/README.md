# SIDEOUT A안 발전 목업

2026-09-23. 사용자가 A 주말 달력을 선택한 뒤 요청한 후속 조정. 실제 web/ 코드와 배포는 변경하지 않았다. 이전 A/B/C 비교는 상위 폴더에 보존했다.

## 선택과 변경

- A의 날짜/시간대 배치, 오늘 표시, 토·일 두 열 유지. 모바일은 시간순 목록. 내 모임을 먼저 재정렬하지 않는다.
- ‘몇 명까지 몇 명’ 문구 삭제. 인원 바는 유지하고 그 오른쪽에 소속 회원용 ‘명단 확인’을 배치.
- 뉴배동 소속 회원에게 뉴배동 신청자 이름만 표시. 하단 별도 줄에 게스트 수 표시. 신청 후 샘플은 소속 15명 + 게스트 6명 = 21명. 게스트 이름은 노출하지 않는다. 여기서 게스트는 해당 모임에 소속되지 않은 참석 인원이라는 표시이며 별도 신청 유형이 아니다.
- 카드의 신청 옆 종 버튼 제거. 우측 상단 정보 아이콘 + ‘상세’ 텍스트가 운동 상세로 이동. 톱니바퀴는 설정 변경을 뜻할 가능성이 있어 사용하지 않았다.
- 상세의 정보/공지/명단 탭 유지. 정보 탭의 운동 정보 아래에 팀편성 배치. 공개 후 팀/대진을 같은 위치에서 보여주고, 별도 팀편성 메뉴도 유지. 두 경로는 같은 팀 표시 함수 사용.
- 공개 전에는 ‘아직 팀편성이 공개되지 않았어요.’와 ‘공개되면 이곳에서 팀과 경기 순서를 확인할 수 있어요.’ 사용. 초안 존재 여부나 완료 시점을 추정하지 않는다. ‘준비 중’보다 실제 열람 상태를 정확히 설명하며 ‘공유’보다 서비스의 게시 동작과 일치한다.
- 공개 전 3개 팀 틀은 ‘화면 구성 예시’임을 표시. 가짜 선수명/실제 초안/고정 팀수 정보를 넣지 않는다. 움직이는 로딩 UI로 표현하지 않는다.
- ‘신청한 운동만’ 체크박스 제거. ‘내 모임만’ 스위치를 뉴배동 모임 필터의 바로가기로 사용. 두 개의 독립 AND 조건이 아니다. 켜기=뉴배동, 끄기=All, 다른 모임 선택=스위치 해제, 뉴배동 선택=스위치 켜짐. 소속 변경 기능이 아니다.

신청/취소/공개 후 활성 팀 확인, 타 모임 공개 전 명단 비노출 등 제품 의미는 유지한다. 실제 인증·저장·마감/후보 경계 처리는 이 목업에 구현하지 않았다. 미래 인원 단계 문구나 내부 실력·프로필·신청 순서도 노출하지 않는다.
