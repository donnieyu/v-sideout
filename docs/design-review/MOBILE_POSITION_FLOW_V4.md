## 확정된 방향

운영자가 처음부터 팀을 편성할 때 **세터 → 레프트 → 센터 → 라이트** 순서로 배정한다. 현재 화면에서는 포지션별 배정만 제공한다. 자율 배치의 화면 선택지는 제거했고, 기존 샘플 로직은 후속 검토를 위해 코드에 보존했다. 자동 배치는 포지션별 흐름의 별도 초안 기능으로 유지한다.

모바일에서는 팀별 현재 자리와 세터 이름을 작은 비교표에 보여주고, 그 아래 선수 풀을 독립적으로 스크롤한다. 한 번 배정하면 같은 포지션의 다음 빈자리로 순환하고, 다음 포지션은 운영자가 하단 버튼으로 이동한다. 완료 전에도 다음 포지션으로 갈 수 있다.

## 현재 화면 동작

- 세 팀의 현재 포지션 자리를 행으로 비교한다. 레프트와 센터는 팀당 두 자리, 세터와 라이트는 한 자리를 표시한다. 앞서 배정한 세터 이름은 팀 이름 아래에서 계속 확인한다.
- 이전 단계의 더 자세한 명단은 `앞선 배정 보기`에서 펼칠 수 있다. 높이 600px 이하에서는 이 펼침을 숨기고 하단 `전체 팀`으로 확인한다.
- 선수 검색과 주/부/전체 후보 범위를 선수 풀 위에 둔다. 선수 풀을 스크롤해도 비교표와 검색은 그대로 보인다. 배정 직후 대상 자리·직전 배정 알림을 갱신한다.
- 팀 자리의 X는 확인창을 거쳐 해제한다. `전체 팀`에서 다시 배정으로 돌아오면 포지션, 현재 자리, 검색어, 후보 목록 스크롤 위치가 유지된다.
- 높이 480px 이하에서는 비교표를 접고 현재 대상 자리와 직전 배정 알림을 유지한다. 이는 가상 키보드가 열린 상황을 대비한 CSS 높이 기준이다. 실제 키보드 동작은 아직 검증하지 않았다.

## 확인한 범위

로컬 샘플에서 모델 검사 67개, 화면 통합 테스트 3개, TypeScript/Vite 빌드가 통과했다. 인앱 브라우저 CSS 뷰포트 390×844, 360×740, 320×568, 320×420에서 배치를 확인했다. 360×740에서 비교표와 후보가 함께 보였고, 320×568에서는 작업 영역을 올린 뒤 후보 카드 한 장이 온전히 보였다. 320×420에서는 비교표가 접히고 후보 풀 148px이 남았다. 선수 풀을 스크롤한 뒤 전체 팀을 왕복해도 목록 위치가 유지됐다.

브라우저 화면 축소는 실기기 터치나 키보드 검증을 대신하지 않는다. 팀 수·정원은 3팀·18명 샘플이며, 4팀·7명 교대, 실제 회원·대기자·우선 편성, 저장·공개와 운영 앱 연결은 이번 체험본 범위가 아니다. 저장 없이 새로고침하면 배정은 초기화된다.

## 다음에 검토할 것

현재의 행별 비교표가 실제 4팀과 긴 이름에서도 충분한지 확인한다. 그다음 초안 저장과 일정 상세 통합에 연결한다. 자율 배치는 포지션별 흐름을 충분히 사용해 본 뒤 별도 모드가 필요한 이유와 전환 규칙을 다시 결정한다.

## 2026-09-26 팀별 이력 표시 보완

`앞선 배정 보기`는 A·B·C를 각각 한 열로 놓고, 같은 팀의 앞선 포지션 선수들을 위에서 아래로 표시한다. 포지션은 행으로 나뉘고 팀 열은 화면 너비에 맞춰 함께 보인다. 높이 601px 이상인 모바일 화면에서는 이력을 펼칠 때 현재 자리 비교표가 접혀 세 팀의 이력 열과 선수 풀이 함께 보인다. 높이 600px 이하에서는 기존대로 `전체 팀`을 통해 확인한다.

360×740 로컬 브라우저에서 세 팀 열, 라이트 단계의 다섯 이전 자리, 아래 후보 카드와 배정 버튼의 동시 노출을 확인했다. 변경 범위의 모델 검사 67개, 화면 검사 5개, TypeScript/Vite 빌드가 통과했다. 실기기 터치 조작은 아직 검증하지 않았다.

## 2026-09-26 현재 자리판의 팀별 열 수정

앞선 변경은 펼치는 이력에만 적용되어, 기본으로 보이는 현재 포지션 배정판은 팀별 행으로 남아 있었다. 현재 배정판도 포지션을 행, A·B·C팀을 열로 바꿨다. 세터 단계는 한 행, 레프트·센터 단계는 두 행으로 표시하며 팀 이름 아래에 기존 세터 배정 정보가 남는다. 360×740 화면에서 팀별 열, 두 포지션 자리, 선수 풀을 함께 확인했고 배정된 선수의 이름과 해제 버튼도 확인했다. 67개 모델 검사와 5개 화면 검사, TypeScript/Vite 빌드가 통과했다.

## 2026-09-26 배정 타일 밀도 조정

기본 배정판의 타일을 72px에서 48px로 축소했다. 이름과 해제 버튼을 같은 가로줄의 독립된 클릭 영역으로 구성하여 겹침을 막고, 레프트·센터 두 행에서 약 48px의 높이를 선수 풀에 돌려준다. 해제 버튼은 32×44px이며 기존 확인창을 유지한다. 긴 이름은 줄바꿈 대신 말줄임 처리된다. 360×740, 320×640, 1280×800 브라우저 화면과 해제 확인창을 확인했다. 모델 67개와 화면 5개 검사, 빌드가 통과했다. 실제 휴대폰에서의 손가락 조작성은 아직 확인하지 않았다.
