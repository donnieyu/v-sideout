# 팀편성 헬퍼 — 후속 기획

2026-09-24 구현 상태: [B안 v3 목업](MOBILE_ALLOCATION_MODES_V3.md)에 **18명·3팀 가상 데이터의 빈자리 자동 배치**를 추가했다. 주/부 포지션 기반의 제한적 시연이며, 아래의 팀 수 선택·우선 보장·교대·실력 균형·저장/공개를 갖춘 전체 헬퍼는 여전히 기획 단계다.

2026-09-23 후속 결정: 최종 목표는 모바일에서 대화·선택으로 헬퍼가 팀편성을 돕고 이후 수동 조정하는 흐름이다. 현재는 **모바일 최초 전체 편성의 A/B 비교**가 우선이며,그 이후 한두 명 수정 과정을 기획한다. 자동 배정/AI/투표 기능은 아직 구현하지 않는다.

[모바일 A/B 및 헬퍼 전환 검토](MOBILE_ALLOCATION_AB_REVIEW.md)는 개발 순서를 구분한다. 최종 헬퍼 경험과 공통 명령 경계는 미리 설계하고,수동 최초 편성 기능부터 개발한 뒤 규칙 기반 헬퍼와 LLM을 연결하는 것을 제안한다. 자유 입력 채팅만으로 만들지 않고 선택 카드·현재 조건·편성 미리보기를 함께 제공한다. 이 제안은 아직 UI 구현 승인이 아니다.

## 코드 기반 초안 생성

1. 신청 인원 확인: 일반 신청자·대기자·신입/임시 인원을 구분한다. 우선 편성 보장 대상은 별도로 식별하고 자동 초안에서 누락하지 않는다.
2. 팀 수 및 팀별 인원 선택: 보통3~4팀, 각6~7명. 가용 인원이 부족하면 임의로 회원을 채우지 않고 빈자리와 부족 포지션을 보여준다.
3. 세터 가용 인원 선택: 팀 수에 맞는 세터 후보를 고른다. 부족한 경우 다음 단계 이동을 강제로 막지 않고 운영자가 조정할 수 있도록 한다. 수동 편성의 최신 고정 세터 자리(전위 오른쪽)를 사용한다. 센터/라이트 점유 선택 단계를 다시 만들지 않는다.
4. 레프트 → 센터 → 라이트 가용 인원 선택: 이미 선택된 회원은 중복 선택 인원이 아닌 동일 회원의 가용 포지션으로 다룬다. 주·부 포지션과 당일 가능한 역할을 구분한다.
5. 초안 생성: 한 회원은 한 팀 한 자리에만 배정한다. 팀별 인원과 세터 분산을 먼저 맞추고, 전용 세터 자리에 배치한다. 기본6명 외 인원은 교대 자리로 두며 복수 교대 줄을 지원하는 수동 편성 규칙을 따른다. 가용 평가 데이터가 있다면 포지션별 균형을 보조 목표로 사용한다.
6. 여러 팀 코트/행 보드에서 검토·수정: 후보 제외 사유, 미배정 인원, 인원/포지션 부족을 운영자에게 보여준다. 배정을 잠그고 나머지만 다시 생성하는 방안은 이후 비교한다.
7. 운영자가 저장 또는 공개: 생성은 초안일 뿐이며 신청 기록·대기 상태·회원 열람 권한을 자동으로 바꾸지 않는다. 기존 공개본은 재공개 전까지 유지한다.

실제 구현 전 결정할 것: 세터 부족 때의 대체 방식, 강제 조건과 참고 조건, 균형 점수 계산, 보장 대상이 팀 정원보다 많을 때의 처리. 자동 초안이 이 문제를 숨기거나 임의로 보장 대상을 탈락시키면 안 된다.

코드 단계는 입력 회원/가용 포지션/팀 구성/평가/제약 → 배정안/미배정/근거로 분리된 함수로 만든다. 같은 입력과 난수 시드로 결과를 재현하도록 한다. 먼저 평가 없이도 작동하는 배정을 검증하고 이후 평가를 보조한다.

## 추후 AI와 평가 데이터

회원 데이터베이스와 포지션별 운영자 평가를 먼저 연결한다. 같은 포지션끼리 두 명을 비교하는 투표를 탐색하되, 단일 토너먼트 승패는 대진 운과 인기 영향을 받으므로 그대로 실력 등급으로 확정하지 않는다. 비교 횟수·최근성·불확실성을 함께 저장하고 반복 비교 기반 점수 방식을 검토한다. 평가 노출 범위와 투표 권한도 별도로 정한다.

AI는 후보안 설명, 제약 해석, 대안 제시를 돕는다. 회원 중복 방지·권한·정원·우선 보장·공개 여부는 코드에서 검증한다. 평가 데이터가 부족한 신입은 낮은 실력으로 단정하지 않는다. AI 연결 이후에도 운영자가 최종 배정과 공개를 결정한다.

기준 문서: [팀편성 기획서](TEAM_ALLOCATION_PLAN.md), [기능 명세서](TEAM_ALLOCATION_SPEC.md). 헬퍼는 Dialog 적용→전체 초안 저장/수정 저장→공개의 구분을 재사용하며 자체 공개 경로를 만들지 않는다.
