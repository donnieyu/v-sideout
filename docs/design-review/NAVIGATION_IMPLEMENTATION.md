# SIDEOUT 화면 이동 적용 기록

2026-09-27 현재 로컬 검토 목업 `/weekend/a-shadcn/`에 적용했다. 기존 디자인 검토 문서에서 모바일에도 경로 표시를 유지하던 제안은 이 결정으로 대체한다. 운영 앱 `web/`과 실제 회원 데이터에는 아직 적용하지 않았다.

## 화면 구조

- 모바일 공통 상단: 홈은 로고와 메뉴, 하위 화면은 44px 이상 뒤로가기·모임명/날짜/화면명·메뉴를 표시한다. 계정 아이콘은 상단에서 빼고 사이드바 하단 프로필에만 둔다.
- 모바일 상세와 두 편집 화면에서는 상단 공통 헤더가 모임과 회차를 알려주므로 본문의 중복 경로와 모임 제목은 숨긴다. 데스크톱은 기존 경로·고정 상세 제목을 유지한다.
- 홈→일정 상세→일정 정보 수정 또는 팀편성 수정은 각각 URL과 브라우저 방문 기록을 가진다. 계정·모임 공간도 별도 화면 주소를 가진다. 뒤로가기는 실제 이전 화면으로 돌아가며, 직접 주소를 연 경우에는 해당 회차 상세 또는 홈으로 돌아간다.
- 홈의 선택 주·필터를 상세 주소에 전달하고, 돌아갈 때 홈의 주·필터·스크롤 위치를 복구한다. 일정 정보 저장과 팀편성 초안 저장·공개 후에는 해당 일정 상세로 돌아간다.
- 일정 정보와 팀편성의 미저장 변경은 화면 안의 뒤로가기, 브라우저 뒤로가기, 메뉴 이동 시 같은 shadcn Dialog로 확인한다. 계속 수정 또는 저장하지 않고 이동을 명시적으로 선택한다. 새로고침·탭 종료는 브라우저의 기본 이탈 확인에 맡긴다. 정보 확인·필터 이동 자체에는 확인창을 띄우지 않는다.

## 검증과 남은 범위

- 로컬 목업 빌드와 대상 테스트 12개 통과. 390px 모바일 홈·상세·계정, 320px 팀편성 편집, 데스크톱 상세를 실제 브라우저에서 확인했다. 일정·팀편성 편집 중 브라우저 뒤로가기→확인창→폐기, 계정 이동→뒤로가기, 직접 팀편성 편집 주소 접근을 확인했다.
- 320×700 화면에서 팀편성 하단 탐색이 화면 밖으로 내려가던 최소 높이 규칙을 제거하고, 탐색 하단이 뷰포트 700px에 맞는 것을 측정했다.
- 샘플 데이터와 편집 내용은 새로고침 후 복구되지 않는다. 실제 로그인·계정 발급, 서버 저장 및 권한 검증, Safari 기종별 스와이프/이탈 확인의 실기기 검증은 후속 작업이다. 외부 사이트 이동 후 동일 화면 복귀, 여러 탭 동시 편집, 로컬 임시 저장은 이번 범위에 포함하지 않았다.
