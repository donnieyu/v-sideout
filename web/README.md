## 새 checkout의 로컬 DB

`web/`에서 `npm ci`와 `npm run build`를 실행하면 `dist/server/wrangler.json`이 생성됩니다. 저장소의 `vite.config.ts`에 있는 로컬 `DB` 바인딩이 이 설정에 포함됩니다. **새 로컬 DB에 한 번만** 다음 두 SQL을 순서대로 적용합니다.

```sh
./node_modules/.bin/wrangler d1 execute DB --config dist/server/wrangler.json --local --persist-to .wrangler/state --file drizzle/0000_windy_omega_red.sql
./node_modules/.bin/wrangler d1 execute DB --config dist/server/wrangler.json --local --persist-to .wrangler/state --file drizzle/0001_glamorous_iron_lad.sql
```

`--local`을 유지하고 운영 D1에는 실행하지 않습니다. `.wrangler/`는 Git에서 제외됩니다. 기존 원본 DB·실회원·계정은 복사하지 않았으며, 이 SQL은 스키마만 생성합니다. 이후 `npm run dev`(개발) 또는 `npm run start`(빌드 기반 로컬 Worker)를 사용합니다. 소스가 변경되면 다시 빌드한 후 start를 실행합니다.

# SIDEOUT / 사이드아웃

뉴배동·히어로즈 예시 모임의 주간 신청·후보 접수·수동 팀 편성 시제품. 실제 계정 운영 전, 샘플 모임에서 핵심 흐름을 검토하는 1차 구현이다.

## 현재 구현

- 회원 화면: 운동 목록·달력, 참석·불참, 상한 도달/마감 이후 후보, 공개된 팀·명단, 본인 신청 기록.
- 운영진 화면: 회차·모집 설정, 시간순 신청 명단, 수동 팀 배정과 포지션, 서버 저장, 공개본 관리.
- 신입·계정 없는 임시 인원는 별도 ‘함께 참여하는 인원’. 마스터·회장만 선택적 팀 배정 및 전체 회원 대리 추가.
- 공지·이벤트·이야기 게시글, 고정, 댓글.
- 서버 저장: D1에 샘플 모임 상태와 revision을 저장하며 낙관적 잠금으로 동시 덮어쓰기를 막는다.

## 현재 경계

사이드바 역할 전환은 샘플 데이터를 확인하기 위한 개발 도구다. 이 값을 실제 인증이나 권한 증명으로 사용하면 안 된다. 사이트는 소유자 전용 비공개로 배포하며 실제 개인정보를 넣지 않는다. 회원용 응답은 운영 정보가 제거된 별도 projection이다.

회원 정보 등록은 마스터가 소속/무소속을 지정해 처리한다. 실제 로그인 계정 발급·운영진 지정·여러 모임 등록은 후속 단계. 그때 실제 인증된 계정에서 모임별 권한을 결정하고, 관계형 테이블로 회원·접수·편성·공개 이력을 분리한다. 현재 샘플 workspace 및 공통 회원 목록 저장 구조를 실제 다중 사용자 인증 구현으로 간주하지 않는다.

빠른 무작위 배치, 객관적 평가/비교 투표, 출석 통계는 미구현이다. 교대 순서 관리는 범위 밖이며 현장에서 결정한다. 날짜·장소·회원은 모두 샘플이다.

## 실행·검증

- `npm run dev`: 개발 화면. 사용 가능한 포트가 출력된다.
- `npx tsc --noEmit`: 타입 확인.
- `node tests/domain.mjs`: 신청/후보/권한/공개/게스트/편성의 도메인 검사.
- `npm run build`: Worker 빌드.
- D1 migration은 `drizzle/`에 있다. 로컬 적용은 초기 한 번만 실행한다.

관련 계획과 화면 설계는 상위 `docs/PRODUCT_PLAN.md`, `docs/SCREEN_DESIGN.md`를 참고한다.

## 확정 화면 적용 (2026-09-23)

- C의 밝은 색감·밀도, B의 필터·세로 모집 카드를 결합. 홈의 중복 타일·공통 공지 띠·규칙 안내 문구를 제거.
- 고정 소속을 사이드바와 계정에 표시. All에서 내 모임을 먼저, 나머지는 시작일 순으로 정렬.
- 진행 바는 18 → 21 → 24 → 28 단계로 표시하며 다음 기준까지의 부족 인원만 안내.
- 소속 회원에게는 같은 소속 신청자의 이름순 명단만 제공. 외부 회원은 전체 인원만 확인하며 발표 후 팀편성표 확인.
- 참석 후 취소 및 팀편성 확인 버튼 제공. 확인은 공개 후 활성화, 취소는 마감 이후 잠금. 회원 화면은 30초마다 / 다시 포커스할 때 갱신.
- 모임별 공지는 카드 종 아이콘, 전체 알림은 사이드바. 서비스 알림은 아직 등록된 항목이 없고 신청 회차의 공개 소식은 저장된 발표 시점에서 가져온다.
- 운영 설정에 선택적 우선 신청 종료 시각 추가. 기간 내 신청한 정규 소속 회원은 상한을 넘어도 보장 대상으로 저장하고, 미배정 상태에서는 공개 거절. 기존 신입의 정규팀 제외·리더 예외 유지.
- 기존 회차에는 우선 기간과 보장을 소급 적용하지 않는다. 운영자가 새로 지정한다.
- 마스터 회원 정보 등록: 소속/무소속·정규/신입을 지정. 공통 회원 ID로 양쪽 모임의 검색 및 대리 편성 가능. 로그인 자격 발급은 별개로 미구현.
- 계정 없는 '임시 인원'과 다른 모임에서 온 실제 회원을 구분. 외부 회원도 같은 참석 신청 버튼 사용.

두 샘플 모임은 서로 다른 D1 workspace 행, 프로필과 공통 회원 목록은 별도 행을 사용한다. 기존 데이터는 schemaVersion 3으로 비파괴 변환하며 기존 신청·포지션·공개본을 유지한다. SQL migration 변경 없음.

검증: 도메인 검사 35개, TypeScript 검사, 실제 로컬 API의 명단/소속 보호·모임 권한·마스터 등록·다중 모임 회원 식별·낙관적 잠금 확인. 이 기록 이후 2026-09-23 디자인 QA를 진행했다. 상세 범위와 한계는 상위 docs/design-review/QA_2026-09-23.md에 기록했다.
